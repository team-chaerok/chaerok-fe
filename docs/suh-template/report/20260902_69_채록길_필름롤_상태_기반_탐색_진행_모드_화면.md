# ⚙️[기능추가][채록길] 필름롤 상태 기반 탐색/진행 모드 화면

## 개요

채록길 탭(`ExploreScreen`)을 **진행중인 필름롤 유무에 따라 두 모드로 전환되는 단일 화면**으로 재구성했다. 필름롤이 없으면 지도·검색·카테고리 필터로 시작할 채록길을 고르는 **탐색 모드**, 진행중이면 진행률·현상 조건·스팟 인증/촬영으로 필름롤을 채워가는 **진행 모드**를 같은 탭에서 보여준다. 지도(kakao_map_sdk)를 채록길 탭에 새로 들이고 마커를 상태별로 분기했으며, 현상(완료) 조건은 프론트 계산 없이 방문 현황 조회 API(`VisitsApi.getVisits`) 응답을 그대로 표기한다.

## 변경 사항

### 도메인 모델 (신규)
- `lib/data/models/place_category.dart`: `categoryGroup`(TOURISM/FOOD/CAFE_DESSERT)·`categoryDetail`(15종)을 `unknown` 폴백 enum으로 승격. 백엔드가 값을 추가해도 파싱이 깨지지 않는다.
- `lib/features/explore/domain/explore_place.dart`: 지역 목록(`PlaceListResponse`)·검색(`PlaceSearchResponse`) 응답을 하나로 정규화한 `ExplorePlace`. `identityKey`는 `NearbyPlaceRecorder`와 동일하게 서버 ID → 외부 ID(`tourContentId`/`kakaoPlaceId`) → 제목+주소 우선순위.
- `lib/features/explore/domain/explore_category_filter.dart`: `ExploreCategoryFilter`(전체/미기록/자연/문화/유적/음식/카페). `categoryGroup` 우선 매칭 + 원본 라벨 키워드 폴백(백엔드가 한글 분류를 줄 가능성 대비).
- `lib/features/film_roll/domain/visit_verification.dart`: `kVisitVerifiableRadiusMeters=100`, `kVisitMinGpsAccuracyMeters=50`, `evaluateVisitGate()` — 중복 인증 → 위치 확보 → GPS 정확도(≤50m) → 거리(≤100m) 4단계 게이트.

### 데이터 (신규)
- `lib/features/explore/data/bookmark_store.dart`: `BookmarkStore`(SharedPreferences JSON 배열, `AppPreferences` 지연 초기화 싱글턴 패턴). `BookmarkedPlace`는 오프라인 카드 렌더용 메타(제목/카테고리/좌표/이미지)를 함께 보관. 손상된 JSON은 초기화.

### 프레젠테이션 (신규)
- `lib/features/explore/presentation/widgets/explore_map_view.dart`: `KakaoMapController`를 State에 보관해 마커 목록 변경 시 다시 그리는 지도 위젯. `ExploreMarkerState` 6종(normal/recommended/visited/next/unvisited/verifiable) 스타일 분기, `didUpdateWidget`에서 id+state diff, `focus` 변경 시 카메라 이동, 세대 카운터로 비동기 경합 방지, `enabled=false`면 네이티브 뷰 미생성.
- `lib/features/explore/presentation/widgets/film_roll_progress_view.dart`: 진행 모드 본문. `FilmRollController`를 재사용해 진행률/스팟 목록/방문 인증/완료를 연결하고, 현상 조건은 `serverFilmRollId`가 있을 때만 `VisitsApi.getVisits`로 조회해 "서로 다른 관광 유형 N/3"으로 표기(없으면 로컬 진행률로 대체). 진행 상태 필터, 다음 장소 강조 카드(방문 인증하기/필름 카메라 열기/다음 코스 둘러보기), 코스 미선택 시 추천 코스 선택 CTA.

### 프레젠테이션 (수정)
- `lib/features/explore/presentation/explore_screen.dart`: `_ExploreMode(loading/exploring/progress)` 컨테이너로 개편. `reevaluate()` 공개 메서드로 진행중 필름롤을 재판별해 모드를 갱신한다. 탐색 모드에 지도·장소 검색(`PlacesApi.searchPlaces`, 350ms debounce)·카테고리 필터·리스트 위 북마크 오버레이·`이 채록길 시작하기` CTA 추가. 필름롤 진입 후·완료 후 `reevaluate()`로 모드 전환.
- `lib/features/home/presentation/main_tab_screen.dart`: `GlobalKey<ExploreScreenState>`를 도입해 `IndexedStack`의 `const` 리스트를 해제하고, 채록길 탭 재진입·카메라 액션 종료 후 `reevaluate()`를 호출해 모드가 갱신되게 배선.

## 주요 구현 내용

**모드 판별.** 화면을 라우트로 나누지 않고 `ExploreScreen` 내부에서 `FilmRollModule.recoverLastActiveFilmRoll()` 결과로 3분기(필름롤 없음 → 탐색 / 코스 미선택 → 코스 선택 유도 / 코스 선택됨 → 진행)한다. `IndexedStack`이 탭을 상시 유지하므로 탭 생명주기 훅이 없어, `MainTabScreen`이 `GlobalKey`로 `reevaluate()`를 명시 호출하는 방식으로 갱신 타이밍을 확보했다.

**현상 조건.** 서버가 카테고리 그룹(TOURISM/FOOD/CAFE_DESSERT) 기준으로 판정하므로 프론트에서 재계산하지 않고 `VisitsApi.getVisits(serverFilmRollId)`의 `visitedCategoryCount`/`requiredCategoryCount`/`visitRequirementMet`를 그대로 쓴다. 서버 필름롤 생성은 위치 인증·로그인·지역 일치 조건에서만 이뤄지므로, `serverFilmRollId`가 없으면 로컬 진행률(`visitedPlaceCount/totalPlaceCount`)만 표시하는 graceful degradation을 적용했다.

**방문 인증 게이트.** 기존에 없던 거리 검증을 도입했다. `evaluateVisitGate()`가 순수 함수로 4단계를 평가하고, 실패 시 사유별 안내 문구를 돌려준다. "필름 카메라 열기"는 촬영·저장만 하고 방문 인증은 하지 않아 게이트의 실효성을 유지한다.

**지도.** 기존 `CourseMapView`는 `onMapReady`가 1회만 발화해 동적 마커가 불가능하므로, 컨트롤러를 보관하고 `didUpdateWidget` diff로 갱신하는 `ExploreMapView`를 새로 만들었다. `CourseMapView`(코스 선택 화면)는 건드리지 않았다.

## 주의사항 / 후속 개선점

리뷰([review/20260902_69](../review/20260902_69_채록길_필름롤_상태_기반_탐색_진행_모드_화면.md))에서 도출된 배포 전 보완 항목:

1. **방문 인증 시 좌표 실시간 재조회** — 현재 게이트는 부모가 보유한 좌표(수 분 전일 수 있음)로 평가한다. `_onVisitTap` 진입 시 `getCurrentPosition()`으로 새 좌표를 받아 평가해야 명세(analyze §e)에 맞다.
2. **북마크 식별자 통일** — 검색 결과(서버 ID)와 지역 목록(외부 ID)에서 같은 장소의 `identityKey`가 달라 북마크 중복·표시 누락 가능. 외부 ID 우선 또는 양쪽 인덱싱 필요.
3. **"미기록" 필터** — 탐색 모드에서 `isRecorded`가 상수 `false`라 "전체"와 동일하게 동작. 완료 필름롤 기록 집계를 붙이거나 칩을 제거/재정의.
4. **검색어 컨트롤러/디바운스 정리** — `TextEditingController` 부재로 지역 변경 시 입력 글자가 남고, `_searchDebounce` 미취소로 이전 지역 키워드가 새 지역에 검색될 수 있음.
5. **현상 조건 로딩 실패 재시도** — `getVisits` 반복 실패 시 "확인하는 중" 문구가 고착. 실패 상태·재시도 어피던스 + 탭 재진입 재조회 필요.
6. **지도 지연 로드** — `IndexedStack` 상시 유지로 첫 프레임에 곧바로 네이티브 뷰가 생성되어 지연 로드가 실효 없음.
7. 신규 도메인 로직(`evaluateVisitGate`, `ExploreCategoryFilter.matches`, `identityKey`, `BookmarkStore`) 단위 테스트 추가.

실기기 수동 QA: 지도 마커(탐색/진행), 모드 전환, 위치 기반 CTA 활성화.
