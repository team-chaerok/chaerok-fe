# ⚙️[기능추가][Auth] Apple 로그인 추가

## 개요

기존 카카오·구글 OAuth 로그인 파이프라인을 그대로 재사용해 Apple 로그인(iOS 전용)을 추가했다. `sign_in_with_apple` 패키지로 Apple identityToken을 획득해 기존 `/api/auth/login`에 전달하며, 재생공격 방지를 위한 nonce 처리를 포함한다. 실기기 검증 과정에서 백엔드 nonce 검증 방식이 사전에 전달받은 명세와 다르다는 점을 발견해 클라이언트를 실제 동작에 맞게 수정했다.

## 변경 사항

### 의존성 · iOS 네이티브 설정
- `pubspec.yaml`: `sign_in_with_apple`, `crypto` 의존성 추가
- `ios/Runner/Runner.entitlements` (신규): `com.apple.developer.applesignin` 엔타이틀먼트
- `ios/Runner.xcodeproj/project.pbxproj`: Runner 앱 타깃 Debug·Release·Profile 3개 빌드 설정에 `CODE_SIGN_ENTITLEMENTS` 추가
- `assets/images/apple-logo.svg` (신규): 로그인 버튼용 흰색 Apple 로고

### 인증 로직
- `lib/features/auth/data/apple_auth_service.dart` (신규): `signIn()`이 Apple identityToken과 재생공격 방지용 nonce 해시값을 함께 반환. 카카오·구글 서비스와 동일하게 사용자 취소를 별도 처리
- `lib/data/models/o_auth_login_request.dart`: `OAuthProvider`에 `apple` 추가, `OAuthLoginRequest`에 nullable `nonce` 필드 추가(카카오·구글 요청 직렬화는 변화 없음)
- `lib/features/auth/presentation/login_screen.dart`: Apple 로그인 버튼·핸들러 추가. iOS에서만 노출되도록 플랫폼 분기 적용
- `lib/features/settings/presentation/my_screen.dart`: 계정 정보 화면의 provider 표시에 Apple 케이스 추가

### 테스트
- `test/data/models/o_auth_login_request_test.dart` (신규): provider 직렬화, nonce 포함/미포함 케이스 검증

## 주요 구현 내용

**로그인 흐름**은 기존과 동일하다 — Apple 인증 시트에서 identityToken을 받아 `/api/auth/login`에 전달하면, 응답이 신규 회원이면 기존 회원가입 화면으로, 기존 회원이면 토큰 저장 후 메인 화면으로 이동한다. 응답 처리 로직은 전혀 손대지 않았다.

**nonce 처리**가 이번 작업의 핵심이었다. Apple 로그인은 재생공격 방지를 위해 클라이언트가 생성한 nonce를 인증 시트에 전달하고, 서버가 이를 identityToken의 서명된 claim과 대조해야 한다. 사전에 전달받은 백엔드 명세는 "클라이언트가 원본(raw) nonce를 보내면 서버가 해싱해서 대조한다"였으나, 실기기로 로그인을 시도한 결과 계속 `401 nonce 불일치`가 발생했다. identityToken을 직접 디코딩해 대조해본 결과 원본 nonce를 해싱한 값이 토큰의 nonce claim과 정확히 일치함에도 서버가 거부하는 것을 확인했고, 이는 **서버가 별도 해싱 없이 요청값과 claim을 그대로 비교**하고 있다는 뜻이었다. 이에 따라 클라이언트가 Apple 인증 시트에 넘겼던 해시값을 요청에 그대로 실어 보내도록 수정했고, 실기기 로그인이 정상 동작함을 확인했다.

## 주의사항

- **백엔드 nonce 계약 재확인 필요**: 현재 구현은 "서버가 nonce를 해싱하지 않고 직접 비교한다"는 실측 동작을 전제로 한다. 사전에 전달받은 명세(서버가 해싱)와 다르므로, 이 동작이 의도된 설계인지 백엔드팀 확인이 필요하다. 만약 추후 서버가 명세대로 해싱 로직을 추가하면 클라이언트가 다시 깨진다.
- **Android 미지원(의도된 범위)**: Apple 로그인 버튼은 iOS에서만 노출된다. Android는 Apple 네이티브 로그인을 지원하지 않아 이번 범위에서 제외했다.
- **회원탈퇴 시 Apple 계정 연동 해제 미구현**: 카카오·구글과 달리 Apple은 클라이언트 SDK에 연동 해제(revoke) API가 없다. 서버측 revoke에는 `authorizationCode`가 필요한데 이번 백엔드 범위에 포함되지 않아, 탈퇴 시 Apple 쪽 서버 연동은 아직 해제되지 않는다. App Store 심사 제출 전 별도 확인이 필요하다.
- **실기기 검증 필요**: Apple 로그인은 시뮬레이터에서 불안정하게 동작할 수 있어 실기기(iOS 13 이상) 기준으로 검증했다.
