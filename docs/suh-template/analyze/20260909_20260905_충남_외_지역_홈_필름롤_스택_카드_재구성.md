## 🎯 구현 목표

1. `OutOfServiceHomeView` 상단 골격을 **단일 `RegionFilmDeck` 위젯**으로 교체. 데이터 계층(`_cache`/`_ensureLoaded`/`_tokens`/seam)은 무손실 유지.
2. 열린 카드 = `Expanded`로 뷰포트 채움 + body만 `SingleChildScrollView` 내부 스크롤. 겹친 탭 3장 + 카드 상단 탭 고정.
3. 겹친 탭 탭 → `_onOpenRegion(r)`: `r`과 현재 열린 지역의 덱 슬롯 **스와프**(나머지 2장 위치 유지) + `_ensureLoaded(r)`.
4. 각 카드에 기존 콘텐츠 위젯(인트로·해시태그·`RegionCarousel`·`RecommendedCourseBanner`·`RegionPlaceStrip`) + 상태 분기(loading/error/empty/ready)를 담는다.
5. `FilmCardFrame`: `CustomPainter`로 찢긴 상단 엣지 + 우측 세로 스프로킷 천공 + 섀도우 근사. 독립 위젯으로 격리(에셋 나오면 교체).
6. 우상단 버튼 행 제거.
7. 가벼운 전환: 열린 카드 `AnimatedSwitcher`(fade + 미세 slide, ~220ms).
8. `flutter analyze` 경고 0 + `flutter test` 전체 통과(기존 테스트 갱신 포함).

**기본 상태**: `_deckOrder = RegionCode.values` = `[gongju, buyeo, seosan, yesan]`. 맨 뒤(`yesan`)가 열림.
겹친 탭 top→bottom = 공주 · 부여 · 서산. (폰 목업 스크린샷과 일치)

  ```dart
    final next = [..._deckOrder];
    final i = next.indexOf(region);
    final openIdx = next.length - 1;
    final tmp = next[i];
    next[i] = next[openIdx];
    next[openIdx] = tmp;                 // region ↔ 현재 열린 지역 스와프
    setState(() => _deckOrder = next);
    unawaited(_ensureLoaded(region));
  }
  ```
- `_ensureLoaded` / `_cache` / `_tokens` / `_RegionData` / `defaultRegionIdResolver` — **변경 없음**.
  (`_RegionData.status` 타입은 이관된 `RegionLoadStatus` 그대로.)
- `build`:
  ```dart
  return Scaffold(
    backgroundColor: ChaerokColors.background,
    body: SafeArea(
      bottom: false,                     // 하단은 MainTabScreen 네비가 처리 (현재 plain SafeArea → 선택적 개선)
      child: RegionFilmDeck(
        deckOrder: _deckOrder,
        dataByRegion: {
          for (final r in RegionCode.values)
            r: (
              status: _cache[r]?.status ?? RegionLoadStatus.loading,
              places: _cache[r]?.places ?? const <PlaceListResponse>[],
            ),
        },
        onOpen: _onOpenRegion,
        onRetry: (r) => unawaited(_ensureLoaded(r, force: true)),
        onExploreRegionRequested: widget.onExploreRegionRequested,
      ),
    ),
  );
  ```
  - `Row[FilmCollectionButton, MyPageButton]` **삭제**. import도 제거.
  - `onRetry` 콜백이 `Future` 반환 시 `discarded_futures` 린트 → `unawaited()` 래핑 또는 `void` 클로저.
