## 현재 상태

### 위치 조회 경로가 **두 갈래**로 갈라져 있다

```
[촬영 지오태그]  visit_capture_screen._onCaptureTap
      └─> LocationPermissionService.getCurrentPosition()  ── geolocator 직접
[진행/방문 게이트] explore_screen._loadCurrentPosition
      └─> LocationPermissionService.getCurrentPosition()  ── geolocator 직접   ← Mock 미개입
[위치 인증 화면]  location_verification_screen._run
      └─> LocationProviderFactory.create()
             ├─ kReleaseMode            → RealLocationProvider
             ├─ !isMockLocationEnabled  → RealLocationProvider
             └─ else                    → MockLocationProvider(regionCode)
                     └─ RealLocationProvider.getCurrentPosition()
                            └─> LocationPermissionService.getCurrentPosition()
```

- `LocationProviderFactory`의 유일한 호출부는 [location_verification_screen.dart:76](../../../lib/features/location/presentation/location_verification_screen.dart#L76). 방문/진행 흐름은 이 팩토리를 **전혀 쓰지 않는다**.
- 그래서 QA가 `my_screen`에서 Mock을 켜도 방문 게이트(`evaluateVisitGate`)에는 실제 GPS가 들어간다 → 전략 문서 P-4.

### `MockLocationProvider` ([mock_location_provider.dart](../../../lib/core/location/mock_location_provider.dart))

- `_regionCoordinates`: `RegionCode → (latitude, longitude)` **1:1**. 공주=`(36.4465, 127.1189)` (시청 인근, 코스 스팟 아님).
- `getCurrentPosition()`이 `accuracy: 0` 하드코딩 → `evaluateVisitGate`의 `position.accuracy > kVisitMinGpsAccuracyMeters(50)` 검사를 **항상 통과**(우회).

### 방문 게이트 ([visit_verification.dart](../../../lib/features/film_roll/domain/visit_verification.dart) — #69, `origin/main`)

```
evaluateVisitGate(position, placeLat, placeLng, alreadyVisited)
  1. alreadyVisited            → alreadyVisited
  2. position == null          → noPosition
  3. accuracy > 50m            → inaccurate
  4. distanceBetween > 100m    → tooFar   (kVisitVerifiableRadiusMeters)
  5. else                      → ok
```

- 호출부: `film_roll_progress_view.dart`의 `_onVisitTap`, `_isVerifiable`, `_buildNextSpotCard` — 모두 `widget.currentPosition`(부모가 화면 진입 시 1회 잡은 값)을 그대로 사용.

### QA UI ([my_screen.dart](../../../lib/features/settings/presentation/my_screen.dart) `_buildMockLocationDebugCard`)

- `if (kDebugMode) ...` 로만 노출. release에서는 안 보임.
- Mock 사용 스위치 + `RegionCode` 드롭다운(지역 선택). **지점 선택 없음**.
- `AppPreferences.setMockLocationEnabled` / `setMockRegionCodeName` 저장.

### `AppPreferences` ([app_preferences.dart](../../../lib/core/config/app_preferences.dart))

- 키: `mock_location_enabled`(bool), `mock_region_code`(String). 싱글턴, `SharedPreferences` 래퍼.

### 사용자 정보 / 테스트 계정 식별 재료

- `UserResponse` ([user_response.dart](../../../lib/data/models/user_response.dart)): `id, provider, nickname, email, role(UserRole.user|admin)`. **`isTester` 없음**.
- 사용자 정보는 캐시 안 됨 — `home_dashboard_screen`, `my_screen`, `profile_edit_screen`, `settings_screen`가 각자 `UsersApi.getMyInformation()`(`GET /api/users/me`) 호출.
- [current_account_sync.dart](../../../lib/features/auth/data/current_account_sync.dart) `CurrentAccountSync.sync()` — 로그인/회원가입/스플래시에서 호출. `AppPreferences.currentUserId`가 이미 있으면 **조기 반환**(네트워크 스킵). 없을 때만 `getMyInformation()` 1회 호출 → id 저장. **`isTester` 지속 저장을 얹기 좋은 지점**(단, 조기 반환 분기 주의).

### 탭 재진입 훅

- `MainTabScreen`이 `GlobalKey<ExploreScreenState>`로 `reevaluate()` 호출 (탭 전환 시, 카메라 종료 시). `reevaluate()`는 **위치를 재조회하지 않는다** → QA가 다른 탭에서 지점을 바꾸고 채록길 탭으로 와도 `_currentPosition`이 갱신 안 됨 (UX 갭, §주의사항).

## 구현 목표

1. `MockLocationProvider`가 (지역 × 선택 지점 인덱스)로 서로 다른 좌표 + 현실적 `accuracy`(0 < x < 50m) 반환.
2. 지역별 하드코딩 테스트 좌표 세트 ≥ 3개 (4개 지역 전부). 각 좌표는 해당 지역 추천 코스 스팟 100m(권장 ≤ 60m) 이내.
3. Mock 좌표가 **방문 게이트까지** 흐른다 — `LocationPermissionService.getCurrentPosition()` 단일 진입점을 mock-aware로.
4. QA/디버그 화면에 "현재 Mock 지점" 선택 UI + `AppPreferences` 저장.
5. release 빌드에서 `user.isTester == true` 계정만 Mock 허용. 그 외/비로그인은 현행대로 항상 Real.
6. 방문 성공 강제 분기 없음 — `evaluateVisitGate` 그대로.

- **좌표 ↔ 코스 스팟 수동 확인 절차**(전략 문서 §7 재수록):

  3. ≤ 60m 채택 / 60~100m 재조정 / >100m 폐기.
  4. 채택 좌표에 `기준 코스·스팟·실측 거리·확인일` 주석.
  5. 코스 데이터 개편 시 재수행 규칙을 `mock_location_spots.dart` 상단 주석에 명시.
- QA 체크리스트(수동):

  - [ ] 각 지점에서 `evaluateVisitGate` 실제 통과(강제 성공 아님) — 멀리 있는 스팟은 `tooFar`.
  - [ ] 촬영 사진 지오태그 좌표가 선택한 Mock 지점과 일치.
