### 📊 분석 요약

**감지된 프로젝트 타입**: Flutter (앱 이름 `chaerok`, SDK `^3.9.2`)
**주요 기술 스택**: `dio`(REST), `drift`+`sqlite3_flutter_libs`(로컬 DB), `camera`, `geolocator`+`permission_handler`, `flutter_secure_storage`, `shared_preferences`, `google_sign_in`/`kakao_flutter_sdk_user`. 라우터 패키지·상태관리 라이브러리(Provider/Riverpod/Bloc) 없음.
**코드 스타일**:
- 파일명 `snake_case.dart`, 클래스 `PascalCase`, 화면은 `StatefulWidget` + `setState`.
- 상태는 콜백 기반 plain controller(`FilmRollController(onStateChanged: ...)`) + 불변 `*State` 값 객체(`FilmRollState.copyWith`) 패턴.
- DI 없이 수동 싱글턴 (`FilmRollModule.instance`, `TokenStorage.instance`, `AppPreferences.instance`, `AppDatabase.instance`) — lazy `??=` 초기화.
- 화면은 항상 `Scaffold(backgroundColor: ChaerokColors.background, appBar: AppBar(backgroundColor: ChaerokColors.background, elevation: 0, title: Text(..., style: ChaerokTypography.titleMedium)))` 형태를 반복.
- 카드형 컨테이너는 `BoxDecoration(color: ChaerokColors.surface, borderRadius: BorderRadius.circular(ChaerokRadius.md), border: Border.all(color: ChaerokColors.border))` 패턴 반복(각 화면에 로컬 `_buildCardContainer`로 중복 구현되어 있음, 공용화 여지 있으나 이번 범위 아님).
- 네트워크 에러는 `try/catch` + `log(..., name: _tag)` + `apiErrorMessage(e)` 스낵바 패턴 일관.

### ⚠️ 주의사항

- **위치 인증 게이트 위치**: `_ensureLocationVerified()`를 홈 대시보드 탭에 그대로 남기기로 했다 — 이는 이슈에 명시된 요구사항이 아니라 회귀 위험을 낮추기 위한 구현 결정이다. 만약 팀이 "탭 전환 자유도"를 우선한다면(예: 위치 인증 실패해도 필름/마이 탭은 볼 수 있어야 함), 게이트를 `MainTabScreen` 최상위로 옮기거나 완전히 채록길 탭 전용으로 옮기는 대안도 가능 — `/implement` 진입 전 확정 필요.
- **디자인 토큰 이원화**: 프리뷰 위젯을 `ChaerokColors`로 바꾸면 원래 디자이너가 의도한 `UiPreviewColors.primary(0xFF465043)`와 미세하게 다른 `ChaerokColors.primary(0xFF4F7A5A)`가 적용된다. 색상 차이는 육안상 크지 않지만, 디자이너 확인이 필요하면 `ChaerokColors`에 새 토큰을 추가하는 대안도 있다.
- **중첩 Scaffold**: `FilmRollCollectionScreen`처럼 자체 `Scaffold`+`AppBar`를 가진 기존 화면을 `IndexedStack`의 tab body로 그대로 재사용하면 Scaffold가 중첩된다 — Flutter에서 정상 동작하는 패턴이지만, `MainTabScreen`은 별도 AppBar를 갖지 않도록 주의(각 탭이 자체 AppBar 유지).
- **카메라 "자유 촬영하기"**: 필름롤과 무관한 촬영을 저장할 도메인 모델(어느 필름롤에도 속하지 않는 사진)이 없다. 이번 계획은 안내 placeholder로 최소 대응하고, 실제 구현은 P2 이슈로 분리.
- **`enterRegion` 파라미터 불일치 가능성**: `FilmRollModule.enterRegion`은 `cityCountyName`(String)을 받는다(`home_screen.dart:151`). 채록길 탭에서 `RegionCode`로 지역을 선택하면 `regionCode.cityCountyName`을 그대로 전달하면 되므로 API 변경은 불필요.
- **HomeScreen 삭제 시점**: 3개 진입점 교체 후 `home_screen.dart`가 고아 파일이 되지만, 절대 규칙에 따라 삭제 전 사용자 승인 필요.
