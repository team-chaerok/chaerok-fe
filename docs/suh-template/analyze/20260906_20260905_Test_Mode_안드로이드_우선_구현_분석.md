## 2. 현재 상태 — 관련 코드 구조

### 2.1 위치 조회 단일 진입점 (이미 존재하는 chokepoint)

```
LocationProviderFactory.create()  ─┐
LocationPermissionService.getCurrentPosition() ─┤─→ MockLocationGate.isActive()
                                                │      ├─ isAllowed(): !kReleaseMode || AppPreferences.isTester()
                                                │      └─ isMockLocationEnabled() (사용자 on/off)
                                                └─→ MockLocationGate.currentMockPosition()
                                                       └─ mockLocationSpots[region][spotIndex] 좌표 + accuracy=12m
```

- [mock_location_gate.dart](../../../lib/core/location/mock_location_gate.dart) — 판정 로직 전부.
- [location_provider_factory.dart](../../../lib/core/location/location_provider_factory.dart), [location_permission_service.dart](../../../lib/features/location/data/location_permission_service.dart) — 둘 다 `isActive()`를 존중. **좌표 주입은 이 한 곳만 바꾸면 방문 게이트까지 흐른다.**
- 방문 게이트 [visit_verification.dart](../../../lib/features/film_roll/domain/visit_verification.dart): `kVisitVerifiableRadiusMeters=100`, `kVisitMinGpsAccuracyMeters=50`. `evaluateVisitGate`는 우회하지 않고 주입 좌표로 통과시킨다.

### 2.2 위치 인증 → 서비스 지역 판정 (공주 "진입")

[location_verification_screen.dart](../../../lib/features/location/presentation/location_verification_screen.dart) `_run()` (L130–254):

1. `LocationVerificationResult.sessionCache` 있으면 재사용 → pop.
2. `LocationProviderFactory.create()` → mock이면 권한 스킵.
3. `locationProvider.getCurrentPosition()` → 좌표.
4. `KakaoLocalApiService.resolveAdministrativeRegion(lat,lng)` → 시/도·시/군.
5. **QA 분기 (현행)**:
   - `forceOutOfServiceArea = MockLocationGate.isAllowed() && AppPreferences.isDebugOutOfServiceArea()`
   - `isOutOfServiceArea = forceOutOfServiceArea || provinceName != '충청남도'`
   - `useDebugFallbackRegion = kDebugMode && isOutOfServiceArea && !forceOutOfServiceArea`
     → 이때만 `provinceName/cityCountyName`을 `충청남도/공주시`로 **대체**하고 계속 진행.
6. `RegionsApi.resolveRegion(...)` → `RegionResponse`(regionId, serviceArea).
7. `PlacesApi.getExternalPlaces(regionId)` → 관광지.
8. 성공 시 `LocationVerificationResult.sessionCache = result` 저장 후 `LocationVerified(result)` pop.

호출부: [home_dashboard_screen.dart](../../../lib/features/home/presentation/home_dashboard_screen.dart) `_ensureLocationVerified()` (L104), [signup_navigation.dart](../../../lib/features/auth/presentation/signup_navigation.dart).
성공 후 `_autoConnectFilmRollEntry()` → `FilmRollModule.resolveFilmRollEntry()` → `EnterRegionUseCase` → 로컬 FilmRoll find-or-create + `FilmRollSyncService.syncFilmRoll()`(best-effort `POST /api/film-rolls`).

> **핵심**: `_run()`이 공주로 정상 성공하면 `sessionCache`가 채워지고, 그 뒤 `POST /api/film-rolls`·홈 자동 연결·`FilmRollSyncService._sessionVerifiedRegion()`(= `sessionCache.region.cityCountyName` 의존)이 **전부 기존 흐름 그대로** 동작한다. → 공주 "진입"은 `_run()`의 5번 분기를 일반화하는 것이 가장 깔끔하다.

### 2.3 진행 모드 지역 이탈 감지 (공주 "이탈")

## 3. 구현 목표 (Android 우선)

1. 정식 `release` 빌드 + **일반 계정**에서 Test Mode 패널·좌표 주입에 **어떤 경로로도 도달 불가**.
   (신뢰 경계 = 패널 가시성 게이트 + `MockLocationGate.isAllowed()` = `!kReleaseMode || isTester()`.
   패널 코드가 AAB에 잔존할 수 있으나 서버 플래그 없이는 inert — §5·§7.)
2. `CHAEROK_TEST_MODE=true` 빌드 **또는** debug 빌드 **또는** 서버 `isTester` 계정에서만 패널 노출.
3. 패널에서 6버튼(공주 진입 / 관광지·음식점·카페 인증 / 공주 이탈 / 초기화)을 순서대로 실행.
4. 우회는 위치 판정(시·도/서비스 지역/이탈 감지)만. 방문 거리·정확도 게이트, 사진·업로드·FilmRoll·현상·릴스는 실제 그대로.
5. 마이 탭 QA 토글 제거 → Test Mode 패널로 통합. **단 기존 Play 심사 Mock 흐름(정식 빌드 + `isTester`)은 패널로 대체돼 유지**된다.
6. `MockLocationGate.isAllowed()`는 **수정하지 않는다**(회귀 위험 최소화). `isActive()`/`currentMockPosition()`에만 세션 분기 추가.

#### (b) dart-define-from-file + 빌드 스크립트

- 신규 `config/prod.json` → `{}` (define 없음)

#### `TestModeSession` 설계

```dart
/// Test Mode 진행 상태를 한곳에서 관리하는 세션 싱글턴.
/// 상태관리 라이브러리가 없으므로 Flutter 기본 [ChangeNotifier]로 변경을 통지한다
/// (외부 의존성 없음). 앱 재시작 시 초기화(P2에서 영속화 검토).
class TestModeSession extends ChangeNotifier {
  TestModeSession._();
  static final TestModeSession instance = TestModeSession._();

  bool gongjuEntered = false;
  bool gongjuExited = false;

  /// 지금 방문 인증하려는 유형. non-null 이면 [MockLocationGate.currentMockPosition]
  /// 이 이 유형의 [testModeSpots] 좌표를 반환한다. 인증 흐름 종료 후 패널이 null 로 되돌린다.
  PlaceCategoryGroup? activeInjectionCategory;

  bool get isInjecting => activeInjectionCategory != null;

  void enterGongju() { gongjuEntered = true; gongjuExited = false; notifyListeners(); }
  void exitGongju() { gongjuExited = true; notifyListeners(); }
  void beginVisit(PlaceCategoryGroup g) { activeInjectionCategory = g; notifyListeners(); }
  void endVisit() { activeInjectionCategory = null; notifyListeners(); }

  void reset() {
    gongjuEntered = false;
    gongjuExited = false;
    activeInjectionCategory = null;
    notifyListeners();
  }
}
```

> `ChangeNotifier`는 Flutter 기본(외부 패키지 아님). 프로젝트 선례는 없으나 다중 리스너
> (패널·진행뷰)를 자연스럽게 지원. 대안: 수동 `List<VoidCallback>` — 구현 시 확정(D-3).

#### `MockLocationGate` 분기 (isAllowed 미변경)

```dart
// isAllowed(): 변경 없음 — !kReleaseMode || AppPreferences.isTester()

static Future<bool> isActive() async {
  if (!await isAllowed()) return false;
  if (TestModeSession.instance.isInjecting) return true;   // ← 추가
  return AppPreferences.instance.isMockLocationEnabled();
}

static Future<Position> currentMockPosition() async {
  final category = TestModeSession.instance.activeInjectionCategory;   // ← 추가
  if (category != null) {
    final spot = testModeSpots[category]!;
    return _position(spot.latitude, spot.longitude);   // accuracy = kMockGpsAccuracyMeters
  }
  // ... 기존 region/spotIndex 경로 유지
}
```

- 세션 분기는 `isAllowed()` 통과가 전제(`isActive` 첫 줄). 정식 빌드 + 일반 계정이면
  `isAllowed()` false → 세션 값이 어떻든 무시된다. 패널도 안 뜨므로 세션 값 자체가 세팅되지 않는다(2중 안전).

- 현행 `useDebugFallbackRegion` 조건을

## 7. 위험 요소 및 대안

| 위험 | 영향 | 대응 |
|---|---|---|
| 패널 코드·`test_mode_spots` 문자열이 정식 AAB에 잔존(`_isTester` 런타임 경로) | 역컴파일 시 Test Mode 존재 노출 | 서버 `isTester` 없이는 완전 inert. `MockLocationGate.isAllowed()` = `!kReleaseMode \|\| isTester()` 가 좌표 주입·`_run` 강제·이탈 강제의 실제 경계. **현행 `MockLocationGate` release 경로와 동일한 신뢰 모델** — 새 위험 아님 |
| `_isTester` 를 패널 게이트에 넣지 않으면 정식 빌드에서 Play 심사 Mock 흐름 파손 | 심사 진행 중 위치 게이트에서 막힐 수 있음 | **게이트 = `AppFlavor.isTestMode \|\| kDebugMode \|\| _isTester`** 로 확정(D-2). 정식+테스터 → 패널 진입, 정식+일반 → 불가 를 회귀 테스트 |

| 패널이 마이 탭(다른 탭)에서 열려 진행뷰와 라이프사이클 분리 | "공주 이탈" 즉시 반영 안 됨 | 진행뷰가 `TestModeSession` 리스너 등록 + 탭 재진입 시 `reevaluate()` 두 경로. QA 가이드에 "이탈 후 채록길 탭으로" 명시 |

- 정식 + 일반 계정: 패널 미노출 → `TestModeSession` 값 세팅 불가 + `isAllowed()` false → 우회 전 구간 불활성.
