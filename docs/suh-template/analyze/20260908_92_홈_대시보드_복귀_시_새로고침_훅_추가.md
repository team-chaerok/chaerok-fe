/// 라이프사이클 콜백이 이 훅으로 진행중 필름롤 · 진행률 · 최근 사진 · 가까운
/// 채록 장소를 재조회하게 한다. [ExploreScreenState.reevaluate]와 대칭 훅.
///
/// 사용자 정보 · 위치 인증 · 날씨는 재조회하지 않는다. 특히 위치 인증을
/// 다시 태우면 캐시 히트 시 [_autoConnectFilmRollEntry]가 코스 선택/필름롤

Future<void> refresh() async {
  if (_isRefreshing) return;
  _isRefreshing = true;

    await _loadRecoveredFilmRoll();

## ⚠️ 주의사항 (위험 요소 및 대안)

| 위험 | 영향 | 대응 |
|------|------|------|
| `refresh()`가 위치 인증 흐름 재트리거 → 탭 전환 중 코스 선택/필름롤 화면으로 튐 | 치명적 | `refresh()` 본문은 `_loadRecoveredFilmRoll()`만. `_ensureLocationVerified`/`_onLocationVerified`/`_autoConnectFilmRollEntry`/`_fetchWeather` **호출 금지**. 코드리뷰 체크 + doc 주석 명시 + T1/T4 테스트로 회귀 방어 |
| `IndexedStack`은 탭 전환 시 `build`/`didChangeDependencies` 미호출 | 훅을 build 계열에 걸면 무효 | 반드시 `MainTabScreen._onTabSelected`의 **명시적 호출**로 처리 (build 의존 금지). 본 계획이 이미 그렇게 설계됨 |
| 빠른 탭 토글로 `refresh()` 폭주 | 경미(중복 로컬 조회) | `_isRefreshing` 가드 + 하위 로드의 기존 `_xxxRequestToken` staleness 방어 |
| `_locationResult == null` 시점(위치 인증 미완료)에 `refresh()` 호출 | 낮음 | `_loadRecoveredFilmRoll`가 `_locationResult` null이면 `_loadNearbyPlaces` skip, 필름롤만 조회 → 안전 no-op |
| `didChangeAppLifecycleState`가 `resumed` 외 상태에서도 불림 | 없음 | `state == AppLifecycleState.resumed` 조건 가드 (`ExploreScreen`과 동일) |
| `WidgetsBindingObserver` remove 누락 | 메모리 누수/유령 콜백 | `dispose`에서 `removeObserver` 필수, 페어 리뷰 |
| 헤더 버튼(필름함/마이) pop 복귀 미갱신 | 낮음(진행률 무관) | 이번 범위 제외, 필요 시 후속 이슈(P2-C안: `onReturn` 콜백) |

**대안 (plan 문서에서 기각, 재확인)**
- 전역 `RouteObserver` + `RouteAware.didPopNext()`: 코드베이스 미사용 신규 패턴 + 탭 전환 별도 훅 여전히 필요 → 기각.
- `IndexedStack` → `LazyIndexedStack`/`PageView` 교체: 채록길 탭 상태 유지·`GlobalKey` 전제 붕괴 위험 → 기각.
