#### 2-1. `lib/features/home/presentation/widgets/folder_deck/folder_card_deck.dart` (신규)

```dart
/// 폴더 탭 카드 스택 — [deckOrder]의 마지막 원소가 "열린" 카드이고 나머지는
/// 탭만 겹쳐 쌓인다. 카드의 시각 요소는 [cardBuilder]에 위임하므로 지역별
/// 홈(RegionCode)·충남 홈(HomeCardTab)이 이 위젯 하나를 공유한다.
/// 애니메이션 상수·좌표 계산은 기존 RegionFilmDeck을 그대로 이전한 것으로,
/// 값을 바꾸지 않는다(회귀 방지).
class FolderCardDeck<T> extends StatefulWidget {
  const FolderCardDeck({
    super.key,
    required this.deckOrder,
    required this.cardBuilder,
    required this.onOpen,
  });

  final List<T> deckOrder;
  final Widget Function(BuildContext context, T tab, bool opened) cardBuilder;
  final ValueChanged<T> onOpen;

  /// 겹친 탭을 열 때 "탭 대상과 현재 열린 카드의 슬롯을 맞바꾸는" 표준 동작.
  /// OutOfServiceHomeView._onOpenRegion / HomeDashboardScreenState._onOpenTab
  /// 둘 다 이 헬퍼로 구현한다.
  static List<T> swapToFront<T>(List<T> order, T tab) {
    if (tab == order.last) return order;
    final next = [...order];
    final tappedIndex = next.indexOf(tab);
    final openIndex = next.length - 1;
    next[tappedIndex] = next[openIndex];
    next[openIndex] = tab;
    return next;
  }

  @override
  State<FolderCardDeck<T>> createState() => _FolderCardDeckState<T>();
}

class _FolderCardDeckState<T> extends State<FolderCardDeck<T>>
    with SingleTickerProviderStateMixin {
  // _RegionFilmDeckState의 _duration/_recedeScaleMin/_recedePeak/_tiltRadians/
  // _staggerFraction/_advancePop/_peek/_hInsetStep 상수를 값 변경 없이 그대로 이전.
  // _controller/_fromOrder/_incoming/_outgoing, initState/didUpdateWidget/dispose,
  // _lerp/_recedeScale/_recedeTilt, build()의 LayoutBuilder+AnimatedBuilder+Stack도 동일.
  //
  // 유일한 차이: _card()에서 `RegionFilmCard(...)`를 직접 생성하던 부분을
  // `widget.cardBuilder(context, tab, open)` 호출로 교체하고, GestureDetector의
  // onTap은 지금처럼 이 State가 계속 감싼다(open || locked ? null : () => widget.onOpen(tab)).
}
```

#### 2-2. `region_film_deck.dart` / `region_film_card.dart` 수정 (삭제 아님)

class RegionFilmDeck extends StatelessWidget {
  const RegionFilmDeck({
    super.key,
    required this.deckOrder,
    required this.dataByRegion,
    required this.onOpen,
    required this.onRetry,
    required this.onExploreRegionRequested,
  });

  final List<RegionCode> deckOrder;
  final Map<RegionCode, RegionFilmData> dataByRegion;
  final ValueChanged<RegionCode> onOpen;
  final ValueChanged<RegionCode> onRetry;
  final ValueChanged<RegionCode> onExploreRegionRequested;

  @override
  Widget build(BuildContext context) {
    return FolderCardDeck<RegionCode>(
      deckOrder: deckOrder,
      onOpen: onOpen,
      cardBuilder: (context, region, opened) => RegionFilmCard(
        region: region,
        status: dataByRegion[region]?.status ?? RegionLoadStatus.loading,
        places: dataByRegion[region]?.places ?? const <PlaceListResponse>[],

        onExploreRegionRequested: onExploreRegionRequested,

### ⚠️ 주의사항

1. **`swapToFront`의 `T == T` 비교** — `HomeCardTab`/`RegionCode` 모두 enum이라 기본
   동등성으로 충분하다. 커스텀 클래스를 탭 타입으로 쓰게 되면 `==`/`hashCode` 오버라이드가
   필요하다는 점을 명시해 둔다(현재는 해당 없음).
2. **`_RegionHomeBody` 추출은 기계적 이동** — `_buildNearbyPlacesSection()`/
   `_buildStartFilmRollCard()`가 지금은 `HomeDashboardScreenState`의 인스턴스 메서드로
   `this._locationResult` 등을 직접 참조한다. `_RegionHomeBody`로 옮기면 이 값들을
   전부 생성자 파라미터로 명시해야 하므로, 이동 시 필드 이름이 다 옮겨졌는지
   (`_isEnteringFilmRoll`, `_isAutoConnectingFilmRoll` 등 빠뜨리기 쉬움) 컴파일러가
   잡아주긴 하지만 리뷰에서 한 번 더 대조 필요.
3. **`region` 탭 라벨의 폴백** — 위치 인증이 끝나기 전(`_locationResult == null`)에도
   덱은 렌더돼야 하므로(로딩 중에도 화면은 그려짐) `'필름롤'` 같은 폴백 라벨이 필요하다.
   위치 인증 완료 시 `setState`로 `_locationResult`가 채워지며 자동으로 라벨이 갱신된다.
4. **`FilmCollectionButton`/`MyPageButton` 파일은 유지** — 위 정정사항 참고. 삭제하면
   `out_of_service_home_view.dart`와 그 테스트가 즉시 컴파일 실패한다.
5. **`RegionFilmDeck`/`RegionFilmCard` 삭제 금지** — 위 정정사항 참고. 대신 내부 구현만
   교체하는 어댑터 패턴으로, `region_film_deck_test.dart`/`region_film_card_test.dart`가
   회귀 검증 도구 역할을 그대로 한다(리팩터링 직후 가장 먼저 돌려볼 테스트).
6. **`_isOutOfService == true` 분기 무변경** — 이번 작업은 `HomeDashboardScreen.build()`의
   서비스 지역(else) 분기만 건드린다. `OutOfServiceHomeView`로의 진입/전환 로직은
   손대지 않는다.
