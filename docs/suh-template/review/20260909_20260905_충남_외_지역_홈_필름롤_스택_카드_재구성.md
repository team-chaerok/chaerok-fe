## 💡 Minor (개선 권장)

### M1. `RegionFilmDeck` 방어 코드 부재
**파일**: `region_film_deck.dart:38-39`
```dart
final open = deckOrder.last;                            // deckOrder 비면 StateError
final peeks = deckOrder.sublist(0, deckOrder.length - 1); // 길이 0이면 sublist(0,-1) → RangeError
```
- **현재**: public 위젯인데 `deckOrder` 비었을 때/1개일 때 방어 없음. 실사용 경로(`OutOfServiceHomeView`는 항상 `RegionCode.values` 4개, 스와프가 길이 보존)에선 발생 불가.
- **제안**: 계약을 문서 대신 코드로.
  ```dart
  assert(deckOrder.isNotEmpty, 'deckOrder must not be empty');
  ```
- **이유**: 위젯 테스트/미래 재사용 시 빠른 실패.

### M2. `_onOpenRegion` — `indexOf == -1` 무방비
**파일**: `out_of_service_home_view.dart:114-116`
```dart
final tappedIndex = next.indexOf(region);
next[tappedIndex] = next[openIndex];   // region이 덱에 없으면 next[-1] → RangeError
```
- **현재**: `_deckOrder`는 항상 `RegionCode.values` 전체를 담으므로 실질 안전.
- **제안**: `if (tappedIndex < 0) return;` 한 줄, 또는 `assert`.
- **이유**: 앞의 `if (region == _open) return;`과 대칭되는 가드.

### M3. 스와프 "순서 유지" 테스트가 위치를 검증하지 않음
**파일**: `test/features/home/presentation/out_of_service_home_view_test.dart` (겹친 탭 전환은 나머지 두 지역 탭 위치를 유지한다)
- **현재**: 서산 탭 후 `공주/부여/예산 필름롤` 텍스트 **존재**만 확인. 공주→부여→예산 **세로 순서**가 뒤바뀌어도 통과한다.
- **제안**: `tester.getTopLeft(find.text('공주 필름롤')).dy < tester.getTopLeft(find.text('부여 필름롤')).dy` 식으로 순서 1건 고정.
- **이유**: 스와프의 핵심 계약(나머지 2장 **위치** 불변)을 회귀 방지.

### M4. `FilmTab` — `onTap == null`일 때도 `HitTestBehavior.opaque`
**파일**: `film_tab.dart:31-33`
- **현재**: 열린 카드 탭(`onTap` 없음)도 탭 이벤트를 흡수한다. 뒤에 받을 위젯이 없어 실害 없음.
- **제안**: `behavior: onTap == null ? HitTestBehavior.deferToChild : HitTestBehavior.opaque` (혹은 그대로 두고 주석 한 줄).
- **이유**: 의도 명확화. 우선순위 낮음.

### M5. `dataByRegion` 맵을 `build()`에서 인라인 생성
**파일**: `out_of_service_home_view.dart:130-138`
- **현재**: `setState`마다 4개 record + Map 새로 만든다. `RegionFilmDeck`/`RegionFilmCard`가 `StatelessWidget`이라 실측 성능 영향은 무시 가능.
- **제안**: 가독성 목적으로 `Map<RegionCode, RegionFilmData> get _deckData => {...}` 게터 추출.
- **이유**: `build` 본문을 레이아웃에 집중. 선택.

### M6. `FilmCardFrame` 그림자 방향 상호작용 — 실기기 확인 필요
**파일**: `film_card_frame.dart:31-37` + `film_tab.dart:41-47`
- **현재**: 열린 카드 `BoxShadow(offset: (0,-2))`(위로) + 겹친 탭들 `BoxShadow(offset: (0,3))`(아래로)가 카드 상단 경계에서 겹친다. 코드상 문제는 없으나 목업의 "겹쳐 쌓인 층" 느낌이 탁해질 수 있음.
- **제안**: QA 토글(`AppPreferences.isDebugOutOfServiceArea`)로 실기기에서 층 구분 확인 후 `blurRadius`/`alpha` 미세 조정.
- **이유**: 순수 시각 튜닝. 스크린샷 근사이므로 디자인 확정 프레임 확보 시 함께.

### M7. `_FilmEdgePainter` 상단 노치가 라운드 코너 위로도 그려짐
**파일**: `film_card_frame.dart:66-76`
- **현재**: `foregroundPainter`는 카드 라운드(radius 24)로 클립되지 않아, 상단 3px 노치 path가 좌우 코너 바깥까지 배경색으로 칠한다. 코너 바깥은 원래 배경색이라 대부분 비가시. 겹친 탭 그림자가 깔린 영역에선 3px 밝은 선이 살짝 보일 수 있음(찢긴 결 의도와 부합).
- **제안**: 거슬리면 노치 path의 x 범위를 `[radius, width-radius]`로 제한.
- **이유**: cosmetic. 현 상태로도 수용 가능.

## ✅ Positive (잘한 점)

- **관심사 분리 명확**: `OutOfServiceHomeView`(상태/데이터) → `RegionFilmDeck`(스택 레이아웃) → `RegionFilmCard`(카드 1장) → `FilmCardFrame`/`FilmTab`(크롬). 크롬을 독립 위젯으로 격리해 향후 에셋 교체 용이.
- **데이터 계층 무손실**: `_cache`/`_ensureLoaded`/`_tokens`/`regionIdResolver`/`placesFetcher` 그대로. 늦게 온 응답 가드 유지. 캐시 hit 시 재요청 없음(테스트로 확인).
- **상태 단일 소스화**: `_selected` → `_deckOrder`(맨 뒤=열림), `_open`은 파생 게터. 스와프는 복사본 mutate 후 `setState`로 불변식 유지.
- **프로젝트 컨벤션 준수**: `require_trailing_commas`/`prefer_const_constructors`/`sort_child_properties_last`, raw 값 `static const` + `// Figma 근사. 토큰 없음.` 주석, `for (final (i, x) in xs.indexed)` 패턴, record typedef(`MockLocationSpot` 등과 동일).
- **전환 애니메이션 격리**: `AnimatedSwitcher` + `ValueKey(open)` + `StackFit.expand` layoutBuilder로 카드 서브트리 교체를 안전하게 처리. `RegionCarousel`의 `PageController`는 지역별 독립 → 전환 중 충돌 없음.
- **테스트 갱신 성실**: 삭제 위젯 테스트 정리, 상태 분기(loading/error/empty/ready)·스와프·콜백을 신규/전환 테스트로 커버. 전체 스위트 그린.
- **디자인 미스매치 정리**: 명세에 없는 우상단 버튼행 제거 + 회귀 테스트(`findsNothing`) 추가.
