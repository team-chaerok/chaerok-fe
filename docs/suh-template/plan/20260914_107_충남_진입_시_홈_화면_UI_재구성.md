## 1. 요약

충남(서비스 지역) 진입 시 보이는 홈 화면(`HomeDashboardScreen`의 서비스 지역 분기)을,
이미 구현된 **충남 외 지역 홈(`OutOfServiceHomeView`)의 폴더 카드 덱 구조**와 통일한다.
단 스택에 쌓이는 카드는 지역 4개가 아니라 **3개 탭** — ① {현재여행지역}시, ② 지난여행
(필름롤 아카이브), ③ 마이페이지 — 이다. 세 탭 모두 카드를 열면 **그 카드 안에서 인라인으로**
내용을 보여주며(별도 화면 이동 없음), 기본으로 열려 있는 카드는 **현재여행지역** 탭이다.

`RegionCode` 전용으로 짜인 `RegionFilmDeck`/`RegionFilmCard`의 스택·전환 애니메이션 로직을
탭 타입 무관 **공통 컴포넌트(`FolderCardDeck<T>`/`FolderCard`)로 일반화**해 두 홈 화면이
공유하고, 지금 `HomeDashboardScreen`이 그리던 헤더/날씨/필름롤 카드/근처 장소 콘텐츠는
그대로 "현재여행지역" 탭의 열린 본문으로 옮긴다. **이번 스코프는 구조(카드 덱 메커니즘 +
탭 3종 배선)까지이며, "지난여행"/"마이페이지" 카드의 실제 화면 구성은 후속 작업**이다
(placeholder로 자리만 잡는다).

## 2. 배경 및 목적

### 문제 / 필요성

이슈 #107 기대 결과 그대로 — 충남 외 지역 홈은 최근(#94) 폴더 카드 덱으로 정렬을 마쳤지만,
충남 진입 시 홈은 예전 구성(스크롤 Column + 우상단 아이콘 버튼 2개) 그대로라 두 화면 간
톤·구성이 어긋난다.

| 항목 | 충남 홈 (현재) | 충남 외 지역 홈 (이미 완료 · #94) |
|---|---|---|
| 상단 구조 | `SingleChildScrollView` + `Column`(헤더/날씨/필름롤/근처장소) | 폴더 카드 4장이 겹쳐 쌓인 덱, 열린 1장 + 탭 3장 |
| 다른 기능 진입 | 헤더 오른쪽 위 아이콘 버튼(필름 모음/마이페이지) → **별도 화면 push** | 해당 없음(지역 전환만) |
| 배경 | `sageLight` 593px 배경 원 | 없음(열린 카드가 뷰포트를 채움) |
| 전환 애니메이션 | 없음(단일 스크롤 화면) | 탭 스와프 + 스케일/틸트 전환(320ms, 확정치) |

### 목표

- 충남 홈 상단을 충남 외 지역 홈과 동일한 **폴더 카드 덱**으로 재구성한다.
- 덱 탭을 3개로 정의한다: 현재여행지역(시) / 지난여행(필름롤 아카이브) / 마이페이지.
- 탭을 열면 **카드 안에서 인라인**으로 내용을 보인다(현재의 화면 push 방식 폐기).
- 기본으로 열려 있는 카드는 현재여행지역 탭.
- 두 홈이 쓰는 폴더 카드 덱 메커니즘을 **하나의 공통 컴포넌트**로 합쳐 중복을 없앤다.

### 범위

**포함**
- `RegionFilmDeck`/`RegionFilmCard`를 탭 타입 제네릭 `FolderCardDeck<T>`/`FolderCard`로 일반화(순수 리팩터링, 충남 외 지역 홈 동작·애니메이션 변화 없음).
- `HomeCardTab` 3종 enum 및 충남 홈의 카드 덱 조립(`HomeDashboardScreen` 서비스 지역 분기 교체).
- 기존 홈 대시보드 콘텐츠(헤더·날씨·필름롤 카드·근처 장소)를 "현재여행지역" 탭 본문으로 이전(로직 변경 없음, 위치만 이동).
- 헤더 우상단 `FilmCollectionButton`/`MyPageButton` 제거.
- "지난여행"/"마이페이지" 탭의 placeholder 본문.

**제외**
- "지난여행"/"마이페이지" 탭의 실제 화면 구성(디자인·데이터 연동) — 사용자가 후속으로 별도 지정.
- `FilmRollCollectionScreen`/`MyScreen`의 Scaffold/AppBar 분리(카드 임베딩을 위한 리팩터링) — 후속 이슈.
- 위치 인증 흐름(`_ensureLocationVerified`, `LocationVerificationOutcome` 분기), 날씨/필름롤/근처 장소 조회 로직 — 변경 없음.
- 충남 외 지역 홈(`_isOutOfService == true` 분기)의 화면 전환 로직 — 변경 없음(내부 덱 컴포넌트만 공유).
- 배경 원 등 비주얼 디테일 재설계, Figma 반영 — 실제 화면 구성 단계에서 판단.

## 3. 요구사항

### 필수 (P0)

- P0-1. 충남 홈 상단이 **폴더 카드 덱**으로 보인다: 열린 카드 1장(뷰포트 채움) + 겹친 탭 2장.
- P0-2. 덱 탭은 정확히 3개: 현재여행지역(시) / 지난여행(필름롤 아카이브) / 마이페이지.
- P0-3. 기본으로 열려 있는 카드는 **현재여행지역** 탭.
- P0-4. 겹친 탭을 누르면 그 카드가 열리며 **카드 안에서 인라인으로** 내용을 보인다 — 별도 화면 push 없음.
- P0-5. "현재여행지역" 탭의 열린 본문은 지금 `HomeDashboardScreen`이 그리던 콘텐츠(닉네임·오늘 날짜·지역명 헤더, 날씨 카드, 진행중 필름롤/시작하기 카드, 가까운 채록 장소 섹션)를 **그대로** 담는다 — 내용·로직 변경 없이 위치만 이동.
- P0-6. 헤더 우상단 `FilmCollectionButton` + `MyPageButton` 아이콘 행 제거(기능이 탭으로 흡수).
- P0-7. 폴더 카드 덱의 쌓임·전환 애니메이션은 `RegionFilmDeck`을 **제네릭 `FolderCardDeck<T>`로 일반화**해 충남 외 지역 홈과 공유한다. 충남 외 지역 홈의 기존 동작·애니메이션·테스트는 회귀 없이 그대로 통과해야 한다.
- P0-8. `flutter analyze` + `flutter test` 전체 통과.

### 중요 (P1)

- P1-1. "지난여행"/"마이페이지" 탭의 열린 본문은 이번엔 최소 placeholder(예: 안내 텍스트)로 자리만 잡는다. 실제 콘텐츠는 후속 작업.
- P1-2. "현재여행지역" 탭 라벨은 실제 지역명을 동적으로 반영한다(예: "공주시 필름롤"). 위치 인증이 아직 끝나지 않아 지역명이 없으면 폴백 라벨을 쓴다.
- P1-3. 닫힌 탭의 미리보기 영역(`closedPreview`, 지역 카드의 `RegionFilmPhoto`에 대응)도 이번엔 placeholder.

### 선택 (P2)

- P2-1. `sageLight` 배경 원의 재도입 여부는 실제 화면 구성 단계에서 판단.
- P2-2. `FilmRollCollectionScreen`/`MyScreen`을 실제로 카드 안에 임베드하는 작업(Scaffold/AppBar 분리 포함) — 별도 이슈로 분리 검토.

## 4. 선택한 접근 방식

### 방식: **A안 — 폴더 카드 덱을 `FolderCardDeck<T>`/`FolderCard`로 제네릭화해 두 홈이 공유**

```
lib/features/home/presentation/widgets/folder_deck/          (신규 공통 위치)
 ├ folder_card_deck.dart
 │    FolderCardDeck<T>(StatefulWidget)
 │      - deckOrder: List<T>, onOpen: ValueChanged<T>
 │      - cardBuilder: Widget Function(T tab, bool opened)
 │      - RegionFilmDeck의 스택 위치(top/hInset)·스케일·틸트·스태거·스왑
 │        애니메이션 상수/로직을 T 제네릭으로 그대로 이전(값 변경 없음)
 │      - static List<T> swapToFront<T>(List<T> order, T tab)  // 스왑 헬퍼
 └ folder_card.dart
      FolderCard(StatelessWidget)
        - color / label / opened / closedPreview / openedBody 파라미터
        - RegionFilmCard.build()의 클리핑(FolderCardClipper)+그림자
          (FolderCardShadowPainter)+탭 라벨 틀만 남기고 지역 전용 참조 제거

충남 외 지역 홈 (리팩터링만, 동작 불변)
 OutOfServiceHomeView
  └ FolderCardDeck<RegionCode>(
        deckOrder: _deckOrder, onOpen: _onOpenRegion,
        cardBuilder: (region, opened) => RegionFilmCard(...),  // 얇은 어댑터로 축소
      )

충남 홈 (신규 조립)
 HomeDashboardScreen (State는 그대로, build()의 서비스 지역 분기만 교체)
  └ FolderCardDeck<HomeCardTab>(
        deckOrder: _deckOrder,           // 기본: [filmArchive, myPage, region] (마지막=열림)
        onOpen: _onOpenTab,              // swapToFront 사용
        cardBuilder: (tab, opened) => switch (tab) {
          HomeCardTab.region       => FolderCard(..., openedBody: _RegionHomeBody(...)),  // 기존 Column 이전
          HomeCardTab.filmArchive  => FolderCard(..., openedBody: _PlaceholderCardBody(...)),
          HomeCardTab.myPage       => FolderCard(..., openedBody: _PlaceholderCardBody(...)),
        },
      )
```

`enum HomeCardTab { region, filmArchive, myPage }`를
`lib/features/home/presentation/models/home_card_tab.dart`에 신규로 둔다.

### 이유

- **중복 제거**: 두 홈이 똑같은 "폴더 탭 카드 스택 + 스와프 전환" UI를 쓰는데, 애니메이션
  상수(스케일/틸트/스태거 320ms 등)는 이미 #94에서 프로토타입 확정치로 굳어 있다. 로직을
  복제하면 한쪽만 고치고 다른 쪽을 놓치는 회귀가 생기기 쉽다.
- **회귀 위험이 낮음**: `FolderCardDeck<T>`로의 전환은 필드 타입을 `RegionCode` → `T`로
  바꾸고 `RegionFilmCard(...)` 직접 생성을 `cardBuilder(tab, opened)` 호출로 바꾸는 정도의
  **기계적 리팩터링**이라, 기존 `region_film_card_test.dart` 등으로 동작 동치를 바로 검증할 수 있다.
- **`HomeDashboardScreenState`의 기존 상태·부수효과(위치 인증, 날씨, 필름롤 복구, 근처 장소)를
  전혀 건드리지 않는다** — `build()`의 렌더링 부분만 교체하므로 회귀 표면이 좁다.
- **placeholder 스코프와 궁합**: "지난여행"/"마이페이지"는 이번에 내용이 없어도, 카드 자체는
  진짜 폴더 카드 덱 컴포넌트를 쓰므로 나중에 `openedBody`만 교체하면 된다.

### 대안

**B안 — 충남 홈 전용 새 덱 위젯 별도 작성 (구조만 모방, 컴포넌트 미공유)**
- `RegionFilmDeck`은 그대로 두고, 비슷한 스택/애니메이션 로직을 가진 별도 위젯(예:
  `HomeCardTabDeck`)을 새로 작성.
- 장점: 충남 외 지역 홈 코드를 전혀 건드리지 않아 그쪽 회귀 위험이 0.
- 선택 안 한 이유: 애니메이션 상수·스왑 로직이 그대로 중복된다. 이후 전환 애니메이션을
  조정할 일이 생기면(예: 프로토타입 값 변경) 두 파일을 매번 동시에 고쳐야 하고, 실수로
  둘이 갈라지면 "충남/충남 외 지역을 오가도 이질감 없는 경험"이라는 이슈 #107의 기대
  결과 자체를 해친다. 이미 결정된 방향(A안)과 배치됨.

## 6. 고려사항 및 위험요소

### 기술적 위험

| 위험 | 영향 | 대응 |
|---|---|---|
| 제네릭화 과정에서 `RegionFilmDeck`의 애니메이션 상수(스케일/틸트/스태거 등 320ms 확정치)를 실수로 바꿈 | 충남 외 지역 홈 시각적 회귀 | 리팩터링 직후 기존 `region_film_card_test.dart`/`out_of_service_home_view_test.dart`를 최우선으로 통과시켜 동작 동치 확인 |
| `T`(탭 식별자)가 `ValueKey`/`Map` 키로 쓰이는데 `HomeCardTab`이 값 기반 동등성을 만족하지 않는 경우 | 스택 애니메이션 오동작 | `HomeCardTab`을 단순 `enum`으로 둔다(참조 동등성 문제 없음) |
