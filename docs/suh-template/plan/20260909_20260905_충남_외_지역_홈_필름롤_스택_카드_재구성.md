## 1. 요약

충청남도 외 지역 사용자에게 노출되는 홈 화면(`OutOfServiceHomeView`)의 상단 영역을,
현재의 "얇은 헤더 4줄(`RegionFilmStrip`) + 분리된 공용 콘텐츠 패널(`RegionDetailPanel`)"
구조에서, **지역별 "필름롤" 카드 4장이 물리적으로 겹쳐 쌓인 덱(deck)** 구조로 재구성한다.
열린 카드는 뷰포트를 채우며 지역 콘텐츠를 **카드 내부 스크롤**로 담고, 안 열린 카드는
상단에 탭만 삐져나와 겹쳐 쌓인다. 탭을 누르면 그 카드가 맨 앞으로 오고 직전에 열려 있던
카드와 **덱 순서를 스위치**한다. 데이터 로딩 계층(`_cache`, `_ensureLoaded`, 테스트 seam)과
하위 콘텐츠 위젯(`RegionCarousel`, `RecommendedCourseBanner`, `RegionPlaceStrip`, 인트로,
해시태그)은 그대로 재사용하고, 상단 골격만 교체한다.

## 2. 배경 및 목적

### 문제 / 필요성

디자인 목업(예산·서산·부여·공주 홈 4종 + 폰 스크린샷)과 현재 구현의 **상단 구조가 완전히 다르다.**

| 항목 | 현재 구현 | 디자인 목업 |
|---|---|---|
| 상단 영역 | 고정 34px 헤더 바 4줄을 `Column`에 나열, 항상 4개 다 노출 | 지역별 대형 카드 4장이 **겹쳐 쌓인 덱**, 열린 1장 + 삐져나온 탭 3장 |
| 콘텐츠 위치 | 헤더와 **분리된** 공용 패널(`RegionDetailPanel`)이 아래에 별도로 그려짐 | 열린 **카드 내부**에 콘텐츠가 들어가고 카드 body가 내부 스크롤 |
| 카드 크롬 | 없음 (헤더는 단색 `primaryDark` 바 + 스프로킷 점 3개) | 라운드 카드 + **찢긴 상단 엣지** + **우측 세로 스프로킷 천공** + 드롭 섀도우 |
| 전환 | `setState`로 선택 지역만 교체, 시각적 스택 변화 없음 | 탭 누르면 해당 카드가 앞으로, 직전 카드와 순서 스위치 |
| 상단 버튼 행 | 우상단 `FilmCollectionButton` + `MyPageButton` 존재 | **없음** (목업에 해당 버튼 없음) |

### 목표

- 상단 영역을 목업의 "스택 필름롤 카드 덱"으로 재구성한다.
- 열린 카드 = 뷰포트 채움 + 내부 스크롤. 안 열린 카드 = 상단에 탭만 겹쳐 노출.
- 탭 탭(tap) 시 해당 카드를 맨 앞으로, 직전 열린 카드와 덱 순서 스위치.
- 디자인에 없는 우상단 버튼 행 제거.
- 필름 질감(찢긴 상단 엣지 + 우측 스프로킷 천공)을 `CustomPainter`로 근사.

### 범위

**포함**
- `lib/features/home/presentation/widgets/out_of_service/` 하위 상단 골격 재구성.
- `OutOfServiceHomeView`의 상단 버튼 행 제거.
- 필름 카드 프레임(크롬) 위젯 신규.
- 가벼운 전환 애니메이션(콘텐츠 크로스페이드 + 탭 재배치 `AnimatedSize`, ~250ms).
- 기존 위젯 테스트 갱신 + 덱 순서 스위치 로직 테스트 추가.

**제외**
- 인증 결과 분기(`LocationVerificationOutcome`), 세션 캐시, `_isOutOfService` 진입 로직 — 변경 없음.
- 데이터 API(`RegionsApi.resolveRegion`, `PlacesApi.getExternalPlaces`) — 변경 없음.
- 하위 콘텐츠 위젯(`RegionCarousel`, `RecommendedCourseBanner`, `RegionPlaceStrip`)의 내부 레이아웃 — 이번엔 손대지 않음(카드 body로 위치만 이동).
- 카드가 물리적으로 슬라이드해 올라오는 고급 모션 연출.
- 필름 프레임 PNG/SVG 에셋 도입(추후 나오면 프레임 위젯만 교체).
- 지역 소개 카피·해시태그·이미지의 백엔드 API화.
- 인서비스(충남 내) 홈 대시보드 — 변경 없음.

## 3. 요구사항

### 필수 (P0)

- P0-1. 상단이 **카드 덱**으로 보인다: 열린 카드 1장(뷰포트 채움) + 그 위에 겹쳐 쌓인 탭 3장.
- P0-2. 열린 카드 콘텐츠는 **카드 내부에서 스크롤**된다. 스크롤해도 겹친 탭 3장과 카드 상단 탭은 고정.
- P0-3. 겹친 탭을 누르면 그 카드가 맨 앞(열림)으로 오고, **직전 열린 카드와 덱 순서를 스위치**한다. 나머지 두 카드 위치는 유지.
- P0-4. 각 카드에 지역별 콘텐츠(로마자 → 정림사지체 제목 → 태그라인 → 해시태그 칩 → 이미지 캐러셀(1/N 뱃지) → "OO 추천 채록길" 배너 → "OO에서 이런 장소를 만나보세요" 가로 스트립)가 들어간다. 기존 위젯 재사용.
- P0-5. 로딩 / 에러(다시 시도) / 빈 목록 상태가 **열린 카드 body 안에서** 표시된다.
- P0-6. 우상단 `FilmCollectionButton` + `MyPageButton` 행 제거.
- P0-7. 기본 열린 지역 = 예산(현행 유지, 목업 스크린샷 기준). 덱 초기 순서 = 공주 · 부여 · 서산 · 예산(맨 뒤가 열림).
- P0-8. `MainTabScreen`의 하단 네비(홈 / 카메라 / 채록길)는 그대로 노출된다(현재도 노출됨 — 회귀 없는지 확인).
- P0-9. 추천 채록길 배너 / "전체보기" → `onExploreRegionRequested(region)` 콜백 동작 유지.
- P0-10. `flutter analyze` + `flutter test` 전체 통과.

### 중요 (P1)

- P1-1. 필름 질감: 카드 **찢긴 상단 엣지** + **우측 세로 스프로킷 천공** + 드롭 섀도우를 `CustomPainter`/`ClipPath`로 근사. 픽셀 완벽 재현은 목표 아님.
- P1-2. 가벼운 전환: 탭 전환 시 열린 카드 콘텐츠 크로스페이드 + 탭 스택 재배치를 ~250ms `AnimatedSize`/`AnimatedSwitcher`로.
- P1-3. 탭 라벨(`OO 필름롤`)은 1줄 + `ellipsis`, 오른쪽에 확장 chevron(») 아이콘.
- P1-4. 겹친 탭의 z-순서/그림자가 "위 카드가 아래 카드를 덮는" 물리감을 준다.

### 선택 (P2)

- P2-1. 목업의 raw 값(탭 높이, 겹침 offset, 제목 36px 등)이 확정 스펙이면 `chaerok_spacing` / `chaerok_typography` 토큰으로 승격 검토(이슈 #94 추가 요청).
- P2-2. 홈 정체성용 `sageLight` 배경 원(인서비스 홈과 동일 패턴)을 덱 뒤에 배치.
- P2-3. 캐러셀 자동 스크롤 / 인디케이터 애니메이션.

## 4. 선택한 접근 방식

### 방식: **C안 — `RegionFilmDeck` 단일 위젯 (탭 레일 + Expanded 열린 카드, 덱 순서 상태 + 가벼운 애니메이션)**

`OutOfServiceHomeView`는 데이터 계층(선택 지역, `_cache`, `_ensureLoaded`, 토큰, 테스트 seam)을
그대로 유지한 채, 상단 골격을 **하나의 `RegionFilmDeck` 위젯**으로 렌더한다.

```
OutOfServiceHomeView (StatefulWidget · 데이터 계층 유지)
 └ Scaffold(background)
    └ SafeArea
       └ RegionFilmDeck(
             deckOrder: _deckOrder,               // 예: [gongju, buyeo, seosan, yesan], last = 열림
             open: _deckOrder.last,
             dataByRegion: _cache,                 // region -> _RegionData(status/regionId/places)
             onOpen: _onOpenRegion,                // 탭 → 덱 순서 스위치 + _ensureLoaded
             onRetry: (r) => _ensureLoaded(r, force: true),
             onExploreRegionRequested: widget.onExploreRegionRequested,
           )

RegionFilmDeck (StatelessWidget)
 └ Column(crossAxisAlignment: stretch)
    ├ for peekRegion in deckOrder.take(3):         // 안 열린 탭 3장, 위에서부터 겹쳐 쌓음
    │    Transform.translate(offset: (0, -overlap * i))   // 겹침 근사
    │      └ FilmTab(label, onTap: () => onOpen(peekRegion))   // 접힌 탭 (높이 = tabHeight)
    └ Expanded
       └ AnimatedSwitcher(~250ms)                 // 열린 지역 바뀔 때 크로스페이드
          └ RegionFilmCard(                       // key: ValueKey(open) — 카드 전체 스왑
                region: open,
                data: dataByRegion[open],
                onRetry / onExploreRegionRequested,
              )

RegionFilmCard (StatelessWidget)
 └ FilmCardFrame(                                  // 크롬: 섀도우 + 찢긴 상단 + 우측 스프로킷
       child: Column
         ├ FilmTab(label, expanded: true, chevron: true)   // 카드 상단 탭 (열린 상태 강조)
         └ Expanded
            └ switch (data.status)
                 loading → Center(ChaerokLoadingIndicator)
                 error   → 안내 + TextButton('다시 시도', onRetry)
                 ready & empty → Center('이 지역의 장소 정보가 없어요')
                 ready   → SingleChildScrollView(               // ★ 카드 내부 스크롤
                             Column[
                               _RegionIntro, _HashtagRow,
                               RegionCarousel, RecommendedCourseBanner, RegionPlaceStrip
                             ])
     )

FilmCardFrame (StatelessWidget)
 └ CustomPaint(painter: _FilmEdgePainter)          // 찢긴 상단 엣지 + 우측 세로 스프로킷 천공
    + DecoratedBox(boxShadow, color: paper, borderRadius)
    + ClipPath(_FilmEdgeClipper)                   // 상단 deckle 클립
```

**덱 순서 스위치 상태 모델** (`OutOfServiceHomeView`):

```dart
List<RegionCode> _deckOrder = const [
  RegionCode.gongju, RegionCode.buyeo, RegionCode.seosan, RegionCode.yesan,
]; // 맨 뒤(yesan)가 열린 카드

void _onOpenRegion(RegionCode r) {
  if (r == _deckOrder.last) return;
  final next = [..._deckOrder];
  final i = next.indexOf(r);
  final openIdx = next.length - 1;
  // r 과 현재 열린 카드의 위치를 스와프 → "다른 카드 열리면 직전 카드와 순서 스위치"
  final tmp = next[i];
  next[i] = next[openIdx];
  next[openIdx] = tmp;
  setState(() => _deckOrder = next);
  unawaited(_ensureLoaded(r));
}
```

- `RegionCode` enum 자체 순서(`gongju, buyeo, seosan, yesan`)와 초기 덱 순서를 일치시켜,
  기본 상태에서 위 탭이 `공주 · 부여 · 서산` 순으로 쌓이고 `예산`이 열린 목업 스크린샷과 맞는다.
- 기존 `_selected` 필드는 `_deckOrder.last`로 대체(파생값). `_ensureLoaded` / `_cache` / `_tokens` 로직은 그대로.

### 이유

- **P0-2(내부 스크롤) + P0-3(스택 스위치)를 정직하게 만족**: `Column[탭 레일, Expanded(카드)]`
  구조라 카드는 뷰포트를 채우고 body만 `SingleChildScrollView`로 내부 스크롤, 탭 레일은 고정.
- **절대 위치(`Positioned`) 수학 최소화**: 탭 겹침만 `Transform.translate`로 근사하면 되고,
  카드 높이·리플로우는 `Expanded`가 처리 → 콘텐츠 길이 가변(캐러셀/장소 수 편차)에 강함.
- **기존 자산 재사용 극대화**: `RegionCarousel` / `RecommendedCourseBanner` / `RegionPlaceStrip` /
  `_RegionIntro` / `_HashtagRow` / `RegionLoadStatus` 분기를 그대로 카드 body로 이동.
  데이터 계층(`_cache`, `_ensureLoaded`, 테스트 seam)은 무손실.
- **테스트 용이**: "탭 탭 → 열린 카드 인트로 제목이 바뀐다", "덱 순서 스위치가 나머지 두 장을
  건드리지 않는다"를 위젯/유닛 테스트로 검증 가능(기존 테스트 구조 유지).
- **애니메이션이 격리됨**: `AnimatedSwitcher`(카드 크로스페이드) + `AnimatedSize`(탭 레일)만
  얹으면 P1-2 충족. 요구가 커지면 A안(절대 위치 슬라이드)으로 확장 여지.

### 대안

**A안 — `Stack` + `AnimatedPositioned` 절대 위치 덱**
- 뷰포트 크기 `Stack`에 카드 4장을 `AnimatedPositioned`로 배치, 탭 offset·카드 높이를 직접 계산.
- 장점: 카드가 물리적으로 슬라이드해 올라오는 고급 모션까지 가능.
- 선택 안 한 이유: 이번 범위는 "가벼운 전환만"으로 확정됨(Q3). 콘텐츠 길이 가변에 취약하고
  (열린 카드 높이를 수동 관리), `Positioned` 안에서 내부 스크롤·SafeArea·키보드 회피 처리가
  번거로움. 모션 요구가 커지면 그때 승격.

**B안 — 스크롤 `Column` 안에 `AnimatedSize` 아코디언 카드 4장**
- 전체가 한 스크롤 뷰. 안 열린 카드는 탭 높이, 열린 카드는 `AnimatedSize`로 body 펼침. 겹침은 음수 margin.
- 장점: 레이아웃 로직이 가장 단순.
- 선택 안 한 이유: "열린 카드가 뷰포트에 고정되고 body만 내부 스크롤"(Q2 확정)이 안 됨 —
  전체 화면 스크롤이라 겹친 탭도 같이 밀려 올라가 목업 느낌과 다름.

## 5. 주요 결정사항

| 결정 | 선택 | 이유 |
|---|---|---|
| 상단 골격 | `RegionFilmStrip` + `RegionDetailPanel` 폐기 → `RegionFilmDeck` + `RegionFilmCard` + `FilmCardFrame` 신규 | 헤더/패널 분리 구조로는 "카드 내부 콘텐츠 + 스택"을 표현 불가 |
| 스택 배치 | 안 열린 탭 3장 전부 상단에 겹쳐 쌓기(위/아래 분할 아님) | Q1 답변 + 목업 스크린샷(예산 열림, 위에 공주·부여·서산) |
| 전환 시맨틱 | 탭 열면 해당 카드 ↔ 직전 열린 카드 **덱 순서 스와프** | Q1 답변("다른 카드가 열리면 기존 열렸던 카드와 순서 스위치") |
| 콘텐츠 스크롤 | 열린 카드 body만 `SingleChildScrollView`, 탭 레일 고정 | Q2 답변("카드 내부 스크롤") |
| 애니메이션 | `AnimatedSwitcher`(크로스페이드) + `AnimatedSize`(탭 레일), ~250ms | Q3 답변("가벼운 전환만"), 기존 spec도 아코디언 애니메이션 범위 외 |
| 필름 질감 | `CustomPainter` + `ClipPath` 근사, 프레임을 독립 위젯(`FilmCardFrame`)으로 격리 | Q4 답변, 기존 spec 리스크 #3(에셋 나오면 교체) |
| 데이터 계층 | `_cache` / `_ensureLoaded` / `_tokens` / `regionIdResolver` / `placesFetcher` **그대로** | 검증된 로직, 테스트 seam 유지. 이번은 UI 재구성만 |
| `_selected` 필드 | `_deckOrder.last` 파생값으로 대체 | 단일 소스(덱 순서)로 상태 관리 |
| 상단 버튼 행 | `FilmCollectionButton` + `MyPageButton` 제거 | 목업에 없음(이슈 #94 기대결과 1) |

## 6. 고려사항 및 위험요소

### 기술적 위험

| 위험 | 영향 | 대응 |
|---|---|---|
| 겹친 탭 z-순서 — Flutter `Column`은 뒤 자식이 위에 그려짐. "위 카드가 아래를 덮는" 물리감이 반대로 날 수 있음 | 탭 그림자/겹침이 어색 | 탭 레일을 역순 렌더 + 각 탭에 아래 방향 그림자, 필요 시 `Stack`으로 탭 레일만 국소 구성 |
| 콘텐츠 길이 가변 — 캐러셀/장소 수가 지역별로 다름. 열린 카드 body가 뷰포트보다 짧을 때 카드 하단이 비어 보임 | 짧은 지역에서 여백 | `Expanded` + body는 `SingleChildScrollView`라 항상 카드가 뷰포트 채움. 하단 패딩(`ChaerokSpacing.xxl`) 유지 |
| `CustomPainter` 찢긴 엣지 + 스프로킷 — 카드 클립과 그림자, 자식 히트테스트가 엣지 밖으로 나가는 문제 | 시각 버그 / 탭 영역 어긋남 | `FilmCardFrame`을 순수 장식 레이어로 격리, 자식은 안전 영역(`EdgeInsets`)에만 배치. `ClipPath`는 장식에만, 콘텐츠 히트박스는 사각형 유지 |
| `AnimatedSwitcher` + 내부 `PageController`(`RegionCarousel`) — 카드 스왑 시 컨트롤러 dispose/재생성 타이밍 | 캐러셀 예외/깜빡임 | `RegionFilmCard`에 `key: ValueKey(region)` — 지역별 독립 서브트리라 기존 `didUpdateWidget` 방어 로직으로 충분한지 `/analyze`에서 확인 |
| 탭 전환 빈도 높을 때 늦게 온 응답이 최신 상태 덮어씀 | 잘못된 장소 목록 표시 | 기존 `_tokens[region]` 최신 요청 가드 유지 — 로직 변경 없음 |
| 하단 네비 + 카드 내부 스크롤 동시 존재 — `MainTabScreen`의 `bottomNavigationBar`와 카드 `SingleChildScrollView` 하단 겹침 | 마지막 장소 카드가 네비에 가림 | body 하단 패딩 유지 + `SafeArea`/`MediaQuery.viewPadding` 확인 |
| 기존 위젯 테스트(`out_of_service_home_view_test.dart`) — `RegionFilmStrip`/`RegionDetailPanel` 위젯 파인더 사용 시 깨짐 | CI 실패 | 테스트를 새 위젯 트리에 맞게 갱신(파인더를 텍스트/`RegionFilmCard` 기준으로). "예산 기본, 서산 탭 → 인트로 '서산'" 시나리오는 유지 |

## 8. 성공 기준

- [ ] 충남 외 지역 홈 상단이 "겹쳐 쌓인 카드 덱"으로 보인다 (열린 카드 1 + 겹친 탭 3).
- [ ] 열린 카드 콘텐츠가 카드 내부에서 스크롤되고, 스크롤 중에도 겹친 탭 3장과 카드 상단 탭이 고정된다.
- [ ] 겹친 탭을 누르면 그 카드가 열리고 직전 열린 카드가 그 자리로 이동(스위치), 나머지 두 카드 위치는 그대로다.
- [ ] 각 카드에 지역 인트로·해시태그·캐러셀(1/N 뱃지)·추천 채록길 배너·장소 스트립이 표시된다.
- [ ] 로딩 / 에러(다시 시도) / 빈 목록 상태가 열린 카드 안에서 표시된다.
- [ ] 우상단 `FilmCollectionButton` + `MyPageButton` 행이 사라졌다.
- [ ] 카드에 찢긴 상단 엣지 + 우측 세로 스프로킷 천공 + 드롭 섀도우가 근사 렌더된다.
- [ ] 탭 전환 시 ~250ms 크로스페이드/리사이즈 전환이 적용된다(카드 물리 슬라이드는 아님).
- [ ] 추천 채록길 배너 / "전체보기" → `onExploreRegionRequested(region)` 동작 유지.
- [ ] `MainTabScreen` 하단 네비(홈/카메라/채록길) 정상 노출, 마지막 장소 카드가 네비에 가리지 않는다.
- [ ] `flutter analyze` 경고 0, `flutter test` 전체 통과(기존 테스트 갱신 포함).
