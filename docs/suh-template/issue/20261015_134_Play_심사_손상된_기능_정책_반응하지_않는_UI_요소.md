# ❗[버그][Play심사] 손상된 기능 정책 위반 - 반응하지 않는 UI 요소

라벨: 작업전
담당자: @SeoHyun1024

---

🗒️ 설명
---

- Google Play 심사에서 **손상된 기능 정책 위반(반응하지 않는 UI 요소: 버튼, 아이콘 등)**으로 거절되었다.
- 위반 위치는 "인앱 환경"으로만 안내되어 특정 화면이 지정되지 않았고, "다른 위치에서도 발생할 수 있으니 앱의 모든 영역을 확인하라"는 안내를 받았다.
- 앱 전체 화면을 점검한 결과, 눌러도 아무 반응이 없거나 실패해도 아무 안내가 없는 요소가 여러 곳에서 확인되었다.

🔄 재현 방법
---

1. 홈의 "가까운 채록 장소" 카드를 누르면 아무 일도 일어나지 않는다.
2. 채록길 탭 지도의 장소 마커를 누르면 아무 일도 일어나지 않는다.
3. 진행 중인 필름롤이 없을 때 카메라 버튼 → "자유 촬영하기"를 누르면 "준비 중" 안내만 나온다.
4. 렌즈가 하나뿐인 기기에서 카메라 전환 버튼을 누르면 같은 카메라가 다시 열리고, 플래시 버튼이 사라진다.
5. 릴스 재생 화면에서 재생 중인데 재생 아이콘이 보여, 첫 탭이 반대로 동작하는 것처럼 보인다.
6. 위치 인증에 실패한 채 홈으로 돌아오면 "필름롤 시작하기" 버튼이 계속 비활성이고 다시 시도할 방법이 없다.
7. 카메라 오류·로딩 화면에 닫기 버튼이 없고, 사진 저장에 실패하면 오류 화면에 갇혀 다시 촬영할 수 없다.
8. 소셜 로그인 실패, 외부 링크(지도에서 보기·전화·길찾기) 열기 실패, 현재 위치 다시 불러오기 실패, 코스 저장 실패, 동기화 재시도 실패 시 아무 안내 없이 원래 화면으로 돌아온다.
9. 하단 내비게이션의 "카메라" 글자, 카메라 닫기 버튼, 장소 상세의 "지도에서 보기"·전화번호는 터치 영역이 너무 작아 빗나가기 쉽다.

✅ 예상 동작
---

- 눌러 보이는 모든 요소는 누르면 화면 이동, 시트 열기, 상태 변경 중 하나가 일어나야 한다.
- 동작이 실패하면 사용자에게 실패 사실과 다음 행동을 안내해야 한다.
- 막다른 상태(비활성 버튼만 남는 화면, 닫기 버튼이 없는 화면)가 없어야 한다.
- 준비되지 않은 기능은 화면에 노출하지 않는다.
- 터치 영역은 손가락으로 누르기에 충분한 크기여야 한다.

- **브라우저**: 해당 없음
- **기기**: Play 심사 기기 (렌즈 1개 기기, 전화 앱 없는 기기 포함 가능)
