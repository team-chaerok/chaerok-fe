## 📝 현재 문제점

- 위치 권한 요청 흐름([lib/features/location/data/location_permission_service.dart](lib/features/location/data/location_permission_service.dart), [lib/features/location/presentation/location_permission_mockup_screen.dart](lib/features/location/presentation/location_permission_mockup_screen.dart))은 마련되어 있으나, 요청한 GPS 좌표로 실제 행정구역(충청남도 여부)을 판별하고 관광지 데이터를 연동하는 로직은 아직 없다.
- [lib/data/models/resolve_region_request.dart](lib/data/models/resolve_region_request.dart), [lib/data/models/region_response.dart](lib/data/models/region_response.dart) 모델이 정의되어 있지만, 이를 실제로 호출하는 API 클래스나 화면이 없어 미사용 상태다.
- [lib/data/remote/places_api.dart](lib/data/remote/places_api.dart)의 `getExternalPlaces`는 regionId 기준 조회만 지원하며, 좌표 기반 반경(약 5km) 주변 관광지 조회 기능은 없다.
- 권한 거부, 좌표 조회 실패, 서비스 지역(충청남도) 외, 관광지 데이터 조회 실패 등 예외 상황에 대한 안내 화면이 없다.

## 🛠️ 해결 방안 / 제안 기능

- 메인 페이지([lib/features/home/presentation/home_screen.dart](lib/features/home/presentation/home_screen.dart)) 진입 시 위치 권한 상태를 확인하고, 허용 상태면 현재 GPS 좌표를 요청한다.
- 권한이 없는 경우 위치 인증 페이지로 이동해 권한을 요청하고, 거부 시 위치 기반 기능 제한 안내(권한이 필요한 이유, 제한되는 기능, 위치 인증 페이지에서 재요청 경로)를 제공한다.
- 좌표 수신에 성공하면 좌표를 행정구역 정보로 변환해 충청남도 포함 여부를 판별한다.
- 좌표 수신에 실패하면 위치 조회 실패 안내 화면(위치 서비스/네트워크 상태 확인 안내, 재시도 버튼, 뒤로가기 시 메인 페이지 복귀)을 제공한다.
- 충청남도 지역이 아니면 서비스 지역 외 안내 화면을 표시하고, 충청남도 전용 기능을 비활성화/이용 제한 상태로 표시하며 메인 페이지로 돌아갈 수 있는 버튼을 제공한다.
- 충청남도 지역이면 TourAPI로 법정동/지역코드를 검증하고, 현재 좌표 기준 반경 약 5km 주변 관광지 후보를 조회한다.
- 관광지 데이터 조회에 실패하면 일시적 서버/네트워크 오류 안내와 재시도 버튼을 제공하고, 성공하면 지역코드를 최종 검증해 검증된 지역 정보와 주변 관광지 데이터를 지도, 코스 추천, 방문 인증 기능에 전달한다.

## ⚙️ 작업 내용

- 좌표 → 행정구역 변환 및 충청남도 판별 로직 추가

- 지역 판별 요청/응답 처리 ([lib/data/models/resolve_region_request.dart](lib/data/models/resolve_region_request.dart), [lib/data/models/region_response.dart](lib/data/models/region_response.dart) 활용)
- 위치 인증 화면([lib/features/location/presentation/location_permission_mockup_screen.dart](lib/features/location/presentation/location_permission_mockup_screen.dart)) 실제 플로우 연동 (Mockup → 실제 화면)
- 예외 화면 구현: 권한 거부(위치 기반 기능 제한 안내), 위치 조회 실패, 서비스 지역(충청남도) 외 안내, 관광지 데이터 조회 실패
