제목: 🚀[기능개선][Auth] 로그인 화면 디자인 명세 반영
라벨: 작업전

---

📝 현재 문제점
---

- 로그인 화면 디자인 시안이 확정되었으나, 현재 `lib/features/auth/presentation/login_screen.dart` 는 소셜 로그인 버튼 2개만 화면 정중앙(`Center` + `MainAxisSize.min`)에 배치한 최소 구현 상태로 시안과 차이가 큼.
- 시안(첨부 이미지) 대비 누락 · 차이 항목:
  1. **로고 영역 전체 누락** — 상단 중앙 로고 마크(챤 심볼) + "채 록" 워드마크(정림사지체) + 태그라인 "필름처럼 남기는 / 나의 여행 기록"(2줄, 회색, 중앙 정렬)이 없음
  2. **레이아웃** — 시안은 로고 블록이 상단~중앙, 버튼 그룹이 화면 하단에 고정. 현재는 버튼만 수직 중앙 정렬
  3. **버튼 라벨 불일치** — 현재 "카카오로 계속하기" / "구글로 계속하기" → 시안 "카카오로 시작하기" / "구글로 시작하기"
  4. **버튼 아이콘 누락** — 시안은 카카오 말풍선 아이콘, 구글 컬러 G 로고가 라벨 왼쪽에 표시됨. `SocialLoginButton` 에 아이콘 파라미터가 없음
  5. **약관 안내 문구 누락** — 버튼 하단 "로그인 시 약관 동의가 필요합니다." (작은 회색, 중앙 정렬)
  6. **버튼 모서리 반경** — 시안은 현재(`ChaerokRadius.md`)보다 큰 라운드
  7. **로고 애셋 부재** — 현재 `assets/` 에 로고 마크 · 브랜드 이미지 애셋 없음(폰트만 존재). 챤 심볼 / 아이콘 애셋 확보 필요
- 참고: 스플래시(`lib/features/splash/screens/splash_screen.dart`)도 "채록" 평문 텍스트만 노출 중이라 동일 로고 자산 정비가 필요할 수 있음(별도 판단).

🛠️ 해결 방안 / 제안 기능
---

- 시안대로 로그인 화면 레이아웃을 재구성한다: 상단·중앙 로고 블록 + 하단 고정 버튼 그룹 + 약관 문구.
- 로고 마크 애셋(SVG/PNG)을 추가하고 `pubspec.yaml` assets 에 등록한다. "채 록" 워드마크는 정림사지체(`Jeongnimsaji-M`) 텍스트 또는 애셋으로 처리한다.
- 태그라인 텍스트("필름처럼 남기는\n나의 여행 기록")를 추가하고 디자인 시스템 타이포 · 컬러 토큰을 사용한다.
- `SocialLoginButton` 에 leading 아이콘 파라미터를 추가한다(카카오 말풍선, 구글 G 로고 애셋). 버튼 라벨을 "시작하기" 로 변경한다.
- 버튼 하단에 약관 안내 문구 위젯을 추가한다.
- 버튼 반경 · 여백 · 간격을 시안 수치에 맞춰 디자인 토큰(`ChaerokRadius` / `ChaerokSpacing`)으로 반영한다. px 하드코딩 금지.
- 로그인 동작 로직(`_onKakaoLoginTap` / `_onGoogleLoginTap` / `_handleLoginResponse`)은 변경하지 않고 UI 레이어만 수정한다.
