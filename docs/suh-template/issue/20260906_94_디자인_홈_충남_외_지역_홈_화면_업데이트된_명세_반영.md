🖌️ 요청 내용
---

- 충청남도 외 지역 사용자에게 노출되는 홈 화면(`OutOfServiceHomeView`)의 디자인 명세가 변경되었다. 새 목업(예산 / 서산 홈 2종) 기준으로 현재 구현을 대조해 정렬해야 한다.
- 현재 구현은 상단 "필름롤" 아코디언(공주/부여/서산/예산) + 지역 인트로(로마자 + 지역명 + 태그라인) + 해시태그 칩 + 이미지 캐러셀 + "OO 추천 채록길" 배너 + "OO에서 이런 장소를 만나보세요" 장소 스트립 구조로, 큰 골격은 목업과 유사하나 세부가 어긋난다.

🎯 기대 결과
---

새 목업과 픽셀·구성 단위로 일치:

1. **상단 영역**: 목업 상단에는 "필름롤" 탭 아코디언만 존재. 현재 구현의 우측 상단 버튼 행(필름 모음 `FilmCollectionButton` + 마이페이지 `MyPageButton`)은 목업에 없으므로 제거 또는 명세대로 재배치.
2. **하단 네비게이션**: 목업은 홈 / 카메라(FAB) / 채록길 3탭 하단 네비를 노출. 충남 외 지역 홈에서도 동일하게 유지되는지 확인(현재 `OutOfServiceHomeView`가 자체 `Scaffold`를 반환).
3. **지역 인트로**: 로마자 캡션(letterSpacing) → 지역명(정림사지체, 36px) → 태그라인 2줄 → 해시태그 칩(sageLight 배경). 폰트/자간/간격/색상을 목업과 재대조.
4. **이미지 캐러셀**: 우하단 `1 / 4` 인디케이터, 라운드/비율 확인.
5. **"OO 추천 채록길" 배너**: 아이콘 + 제목 + 서브텍스트 + chevron, 배경/여백 확인.
6. **"OO에서 이런 장소를 만나보세요"**: 우측 "전체보기 >" + 가로 스크롤 장소 카드(썸네일 / 핀 아이콘 + 장소명 / 한 줄 설명).
