제목: 🚀[기능개선][Home] 홈 화면 디자인 명세 반영 · 기능별 API 연동 점검
라벨: 작업전

---

📝 현재 문제점
---

- 홈 화면 디자인 시안이 확정되었으나, 현재 `lib/features/home/presentation/home_dashboard_screen.dart` 는 "대략적인 구조"만 잡힌 상태로 디자인 명세(레이아웃 · 구성 요소 · 인터랙션)와 차이가 큼.
- 디자인대로 개발하기 전에, 홈 화면 각 섹션이 실제 API / repository 에 연결되어 있는지 연동 현황이 혼재되어 있어 점검이 필요함.
- 현재 상태 1차 점검 결과:
  - **헤더(인사말 / 현재 지역)** — `UsersApi.getMyInformation()` + `LocationVerificationResult` 연동됨
  - **날씨 카드** — `WeatherApiService.getCurrentWeather()` (기상청) 연동됨
  - **진행 중 필름 롤 카드 / 최근 촬영 캐러셀** — 로컬 DB(`FilmRollModule.recoverLastActiveFilmRoll`, `photoRepository.findByFilmRoll`) 연동됨. 단, 서버 `FilmRollsApi.getCurrentFilmRoll` / `VisitsApi.getVisits` 와의 상태 정합성은 미확인
  - **가까운 채록 장소 리스트** — 위치 인증 흐름에서 조회한 `PlacesApi.getExternalPlaces` 결과를 재사용. 단, 카드 탭 핸들러가 비어 있음(`RecommendedPlaceCard(... onTap: () {})`) → 장소 상세(`PlacesApi.getPlaceDetail`) 미연동
  - **장소 카테고리 메뉴(`PlaceCategoryMenu`)** — 홈 화면에는 미노출. 노출 중인 채록길 탭에서도 카테고리별 필터링 API 연동 없이 선택 인덱스만 변경됨
  - **사진 / 썸네일 영역** — `_PlaceImagePlaceholder`(CustomPaint), `FilmRollArtwork` 등 placeholder 로 대체되어 실제 이미지 미연동
  - **추천 코스(`CoursesApi.getRecommendedCourses`) · 필터(`FiltersApi`)** — 디자인 명세에 관련 섹션이 있을 수 있으나 현재 홈에서는 미사용
- 디자인 시안 링크 / 스펙이 이슈에 첨부되어야 정확한 개발 범위를 확정할 수 있음.

🛠️ 해결 방안 / 제안 기능
---

- **디자인 명세 ↔ 데이터 소스 매핑표 작성**: 시안의 각 섹션(헤더 / 날씨 / 필름 롤 진행 / 최근 사진 / 가까운 채록 장소 / 카테고리 / 추천 코스 등)마다 필요한 API · repository 와 응답 필드를 매핑한다.
- **기능별 API 연동 현황 점검**: 각 섹션을 `연동됨` / `부분 연동(핸들러 미구현)` / `mock·placeholder` / `미연동` 으로 분류해 표로 정리한다.
- **미연동 · 부분 연동 항목 구현**:
  - 가까운 채록 장소 카드 탭 → 장소 상세 화면 이동(`PlacesApi.getPlaceDetail`) 연결
  - 카테고리 메뉴를 디자인대로 홈에 배치하고, 선택 시 장소 목록 필터링 동작 연결 (클라이언트 필터 또는 API 파라미터 방식 확정)
  - placeholder 아트워크를 실제 이미지 렌더링으로 교체 (디자인이 실사진을 요구하는 섹션 한정)
  - 서버 필름 롤 / 방문 API 와 로컬 상태 정합성 확인
- **디자인 명세대로 레이아웃 반영**: 간격 · 타이포 · 컴포넌트 변형(`RecommendedPlaceCard.isFeatured` 등)을 명세대로 적용한다. 디자인 시스템 토큰(`ChaerokSpacing` / `ChaerokColors` / `ChaerokTypography`)을 사용하고 px 하드코딩은 금지한다.
- **모든 섹션은 하드코딩 / mock 없이 실제 API · repository 연동 상태로 구현**한다. 로딩 · 에러 · 빈 상태 디자인 정의가 필요하다.
