# ⚙️[기능추가][채록길] 필름롤 상태 기반 탐색/진행 모드 화면

📝 현재 문제점
---

- 채록길 탭([lib/features/explore/presentation/explore_screen.dart](../../../lib/features/explore/presentation/explore_screen.dart))은 진행중인 필름롤 유무와 상관없이 항상 "지역 선택 → 관광지 리스트 → 필름롤 시작하기" 단일 화면만 보여준다.
- 이미 필름롤을 진행중인 사용자가 채록길 탭에 들어오면, 자기가 지금 뭘 채워가고 있는지(진행률·다음 장소·인증 상태)를 이 탭에서 전혀 확인할 수 없다. 진행 정보는 별도 화면([lib/features/film_roll/presentation/page/film_roll_screen.dart](../../../lib/features/film_roll/presentation/page/film_roll_screen.dart))에 흩어져 있고, 카메라 액션([lib/features/home/presentation/main_tab_screen.dart](../../../lib/features/home/presentation/main_tab_screen.dart))으로만 우회 진입 가능하다.
- 탐색(고르는 중)과 진행(수행하는 중)은 사용자 심리와 화면 목적이 다른데, 지금은 같은 UI라서 "지금 뭘 해야 하는지"가 불명확하다.
- 지도·마커·필터·하단 시트·CTA가 모두 탐색 기준으로만 고정돼 있어 진행중 사용자에게 필요한 방문 인증·촬영 흐름을 유도하지 못한다.

🛠️ 해결 방안 / 제안 기능
---

- 채록길 화면을 **두 개로 분리하지 않고**, 진입 시 진행중인 필름롤 유무로 모드를 전환하는 단일 화면 구조로 만든다. 지도·리스트 뼈대는 유지하고 카드 내용·CTA·마커 상태·진행률/필터만 모드별로 바꾼다.

```
채록길 화면 진입
  └─ 진행중인 필름롤 있음?
       ├─ NO  → 탐색 모드 (채록길 고르기)
       └─ YES → 진행 모드 (필름롤 채우기)
```

- **탐색 모드 (필름롤 선택 전)** — 목적: 어떤 채록길을 시작할지 고르기
  - 지역 선택(공주/부여/서산/예산), 장소 검색, 카테고리 필터(전체/미기록/자연/문화/카페/음식/유적지)
  - 지도 상단 + 하단 시트에 주변 장소/추천 채록길 리스트(거리·유형·요약, 가까운 순/추천 정렬)
  - 탐색용 마커: 주변 장소 마커, 카테고리별 마커, 추천 장소 강조
  - CTA 우선순위: ① 이 채록길 시작하기 ② 자세히 보기 ③ 저장/북마크
  - 문구 예시: "공주에서 시작할 채록길을 골라보세요", "현재 위치 근처에서 기록할 수 있는 장소를 찾았어요"

- **진행 모드 (필름롤 선택 후)** — 목적: 선택한 필름롤을 진행하고 기록하기
  - 상단: 진행중인 필름롤명 + 방문 진행률(0/3 ~ 3/3) + 현상(완료) 조건 안내
  - 선택한 채록길의 스팟 목록 + 각 장소 인증 상태 + 현재 위치 기준 인증 가능 여부
  - 필터를 진행 상태 기준으로 교체: 전체/미방문/인증 가능/방문 완료/촬영한 장소
  - 진행 상태 마커: 방문 완료(체크), 다음 장소(강조 핀), 미방문(기본 핀), 인증 가능(원형 하이라이트)
  - 하단 카드는 "다음 장소" 하나를 강조(6a 스타일)하되 내용은 진행 정보로 교체
  - CTA 우선순위: ① 방문 인증하기 ② 필름 카메라 열기 ③ 다음 장소 보기
  - 문구 예시: "공주 필름롤 진행 중", "서로 다른 관광 유형 1/3곳을 기록했어요", "다음 장소에 도착하면 방문 인증을 할 수 있어요"

- 모드 전환 시 값들의 매핑

  | 구분 | 탐색 모드 | 진행 모드 |
  |------|-----------|-----------|
  | 화면 목적 | 채록길 탐색 | 필름롤 진행 |
  | 지도 역할 | 주변 장소 탐색 | 선택 코스 진행 확인 |
  | 하단 시트 | 주변 장소/채록길 리스트 | 진행률/다음 장소/인증 상태 |
  | CTA | 시작하기 | 방문 인증하기 / 촬영하기 |
  | 장소 카드 | 거리, 유형, 요약 | 인증 여부, 진행 상태 |
  | 필터 | 전체/미기록/자연/문화/카페 | 미방문/인증 가능/완료 |
  | 상태 표시 | 추천, 가까운 순 | 1/3 완료, 현상 조건 |

⚙️ 작업 내용
---

- 채록길 탭 진입 시 진행중 필름롤 조회 → 모드 판별 로직 추가 (`FilmRollModule.recoverLastActiveFilmRoll` 재사용, 코스 미선택 상태 처리 포함)
- 탐색 모드: 기존 `ExploreScreen` 구조 정리 — 장소 검색 입력, 카테고리 필터 항목 확장(음식/유적지), 하단 시트에 거리·유형·요약 노출, `RecommendedPlaceCard` 재사용
- 진행 모드 화면 구성: 진행률 헤더 카드, 진행 상태 기준 필터, 스팟 목록 + 인증 상태, "다음 장소" 강조 카드, 방문 인증/필름 카메라 CTA (기존 `FilmRollScreen`·`VisitCaptureScreen` 흐름 연결)
- 지도 위젯의 마커 상태 분기: 탐색용 마커 / 진행 상태 마커(완료·다음·미방문·인증 가능) — `CourseMapView` 확장 또는 신규 위젯 검토
- 현재 위치 기준 인증 가능 여부 판정(거리 임계값) — `Geolocator.distanceBetween` 활용, 판정 기준값은 위치 인증 로직과 일치시키기
- 현상(완료) 조건 안내 문구 표기 (예: "서로 다른 관광 유형 N/3")
- 모드별 문구/CTA 카피 반영
- 진행 모드에서 필름롤 완료 시 탐색 모드로 자연스럽게 복귀하는 처리
