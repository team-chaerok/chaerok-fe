제목: ⚙️[기능추가][Home] 홈 화면 명세 기반 구조/기능 재구현
라벨: 작업전

---

📝 현재 문제점
---

- 현재 홈 화면(`lib/features/home/presentation/home_dashboard_screen.dart`)은 최근 5탭 재구성 작업(계획 문서: `docs/suh-template/plan/20260802_20260730_홈_화면_재구성_및_하단_네비게이션_5탭_도입.md`) 이후 헤더(인사말/지역명)와 진행 중인 필름 롤 카드(`ActiveFilmRollCard`)만 노출하고 있어, 목표 명세(첨부 스크린샷 기준) 대비 기능/구조가 임의로 축소되어 있음.
- 스크린샷 기준 명세에 있는 아래 요소가 현재 구현에 없음:
  1. 날씨 카드 — 지역명 + 실시간 날씨 정보. 날씨 데이터 연동 자체가 코드베이스에 존재하지 않음.
  2. "OO 필름 롤" 사진 프리뷰 캐러셀 — 촬영 진행률(예: 12/27)과 촬영된 사진 가로 스크롤 미리보기. 계획 문서상 "최근 촬영 사진 프리뷰"는 P1으로 명시된 채 미구현 상태로 남아있음.
  3. "가까운 채록 장소" 리스트 — 현재 위치 기반 근처 장소 카드 리스트(사진/이름/카테고리/거리/채록 여부). 현재는 `lib/features/explore/presentation/explore_screen.dart`(채록길 탭)에서만 유사 기능(`PlacesApi.getExternalPlaces`, `RecommendedPlaceCard`)이 제공되고 홈 대시보드에는 노출되지 않음.
- 위 항목이 비어있는 상태로는 사용자가 홈 화면에서 오늘의 기록 맥락(날씨, 진행 중인 필름 롤 현황, 주변 채록 가능 장소)을 파악할 수 없음.

🛠️ 해결 방안 / 제안 기능
---

- 홈 화면 명세(스크린샷 기준)에 정의된 정보 구조를 기능/구조 관점에서 반영한다. 디자인(색상, 레이아웃 세부 수치 등)은 이번 작업 범위에서 제외하고, 데이터·컴포넌트 구조만 구현한다.
  1. 날씨 카드 섹션 추가 — 지역명 + 날씨 상태/기온을 표시. 날씨 데이터 소스(외부 날씨 API 연동 또는 기존 위치 확인 흐름과 연계) 확정 필요.
  2. 필름 롤 캐러셀 섹션 — 기존 `ActiveFilmRollCard`를 진행률 + 촬영된 사진 리스트를 가로 스크롤로 보여주는 형태로 확장. 계획 문서의 P1 "최근 촬영 사진 프리뷰" 항목을 이번 작업으로 승격하여 반영.
  3. "가까운 채록 장소" 섹션 — 홈 대시보드에 현재 위치 기반 근처 장소 리스트 노출. `explore_screen.dart`에서 사용 중인 `PlacesApi`/`RecommendedPlaceCard` 로직을 재사용하거나 공용 컴포넌트로 추출. 각 카드에 채록(기록) 완료 여부 상태 표시 포함.
  4. 각 섹션은 하드코딩/mock 데이터 없이 실제 API·repository 연동 상태로 구현한다.

⚙️ 작업 내용
---

- 날씨 데이터 연동 방식 조사 및 날씨 카드 위젯/데이터 레이어 추가
- `home_dashboard_screen.dart`에 필름 롤 진행률 + 사진 캐러셀 컴포넌트 추가 (기존 `ActiveFilmRollCard` 확장 또는 신규 위젯)
- "가까운 채록 장소" 리스트를 홈 화면에 노출하는 컴포넌트 추가 (기존 채록길 탭 장소 조회 로직 재사용)
- 관련 provider/repository 데이터 연동 및 API 응답 매핑
- 명세 대비 기능 스펙 검증 (디자인 QA는 범위 제외)
