# ❗[버그][위치인증] 기존 회원도 앱 진입 시 위치 인증 화면이 노출됨

- **라벨**: 작업전
- **담당자**: @SeoHyun1024

---

🗒️ 설명
---

- 위치 인증 화면(지도 미리보기 + 안내 + FAQ + CTA가 있는 전체 화면)은 **회원가입 직후에만** 노출되어야 한다. 기존 회원은 앱 진입 시 이 화면 없이 **조용히 현재 위치만 확인**(권한 확인 → 좌표 획득 → 지역 판별)해야 한다.
- 현재는 `HomeDashboardScreen._ensureLocationVerified()`가 `LocationVerificationResult.sessionCache`가 비어 있으면(= 앱 재실행 시 항상) 회원가입 여부와 무관하게 `LocationVerificationScreen`을 push한다.
- 스플래시에서 세션이 `authenticated`인 기존 회원도 곧바로 `MainTabScreen` → 홈 진입 시 위치 인증 화면을 마주하게 된다.

🔄 재현 방법
---

1. 이미 가입되어 로그인 세션이 남아 있는 계정으로 앱을 완전 종료한다.
2. 앱을 재실행한다 → 스플래시 → 홈(`MainTabScreen`)으로 진입.
3. 홈 위에 위치 인증 화면(idle 뷰)이 그대로 뜨는 것을 확인한다. (회원가입을 하지 않았는데도 노출됨)

📸 참고 자료
---

- `lib/features/home/presentation/home_dashboard_screen.dart` — `_ensureLocationVerified()`: 세션 캐시가 없으면 무조건 `LocationVerificationScreen` push
- `lib/features/auth/presentation/signup_navigation.dart` — `toMainViaLocationVerification()`: 회원가입 성공 직후 위치 인증 화면 경유 (여기서만 노출되어야 함)
- `lib/features/splash/screens/splash_screen.dart` — 기존 회원(`SessionStatus.authenticated`)은 `MainTabScreen`으로 직행
- `lib/features/location/presentation/location_verification_screen.dart` — 인증 흐름 오케스트레이션(`_Step.idle` 등 UI 스텝)
- `lib/features/location/data/location_verification_result.dart` — `sessionCache` / `outOfServiceSessionCache`

✅ 예상 동작
---

- 회원가입 완료 직후(`SignupNavigation.toMainViaLocationVerification` 경로)에만 위치 인증 화면을 노출한다.
- 기존 회원이 앱에 진입하면 위치 인증 화면으로 전환하지 않고 백그라운드에서 권한 확인 → 좌표 획득 → 지역 판별을 수행한다.
  - 권한이 이미 허용된 경우: 화면 전환 없이 결과만 홈에 반영(날씨 / 가까운 채록 장소 / 필름롤 자동 진입).
  - 권한 미허용·위치 실패·서비스 지역 외인 경우에만 안내(스낵바 또는 기존 위치 인증 화면 / 충남 외 지역 홈)로 폴백한다.
