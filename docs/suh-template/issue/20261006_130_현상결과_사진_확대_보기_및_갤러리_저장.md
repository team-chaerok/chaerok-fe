# ⚙️[기능추가][현상결과] 현상 결과 사진 확대 보기 및 갤러리 저장

라벨: 작업전
담당자: @SeoHyun1024

---

📝 현재 문제점
---

- 현상 결과 화면의 "오늘의 사진"에서 전체 보기를 누르면 촬영한 사진이 3열 그리드로 보이지만, 사진을 눌러도 아무 반응이 없다.
- 작은 썸네일로만 볼 수 있어 사진을 크게 보거나 확대할 수 없다.
- 사용자가 찍은 사진을 기기 갤러리에 저장할 방법이 없다. 릴스만 저장할 수 있다.
- 관련 파일: `film_roll_result_photos_screen.dart`, `film_roll_result_photo_image.dart`

🛠️ 해결 방안 / 제안 기능
---

- 전체 사진 화면에서 사진을 누르면 전체 화면 사진 보기로 이동한다.
- 사진 보기에서는 손가락으로 확대·축소할 수 있고, 좌우로 넘겨 다른 사진을 볼 수 있다.
- 사진 보기에서 저장 버튼을 누르면 현재 사진을 기기 갤러리에 저장한다.
- 촬영 사진은 기간 제한 없이 언제든 저장할 수 있다 (#127의 상시 조회 정책과 동일).

⚙️ 작업 내용
---

- 전체 화면 사진 보기 화면 추가 (확대·축소, 두 번 탭 확대, 좌우 넘김, 현재 위치 표시)
- 확대한 상태에서는 좌우 넘김이 확대 이동과 겹치지 않도록 처리
- 갤러리 저장 기능 추가 (기기에 보관된 사진은 바로 저장, 서버 사진은 내려받은 뒤 저장)
- 저장 성공·실패 안내
- 촬영 원본으로 대체된 사진은 사진 보기에서도 "필터 미적용" 표시 유지
- 사진 보기 이동, 확대, 저장에 대한 테스트 추가
