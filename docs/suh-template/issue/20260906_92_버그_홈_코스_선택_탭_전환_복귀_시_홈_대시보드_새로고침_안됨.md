# ❗[버그][홈] 코스 선택·탭 전환 후 홈으로 복귀 시 홈 대시보드가 새로고침되지 않음

- **라벨**: 작업전
- **담당자**: @SeoHyun1024

---

🗒️ 설명
---

- 홈에서 코스를 선택하고 나오거나, 다른 탭에 갔다가 홈 탭으로 돌아왔을 때 홈 대시보드가 갱신되지 않고 이전 상태(진행중 필름롤 카드 / 진행률 / 가까운 채록 장소 / 사용자 정보)를 그대로 보여준다.
- `MainTabScreen`은 `IndexedStack`으로 홈 / 채록길 탭을 상시 유지한다. `ExploreScreen`은 `reevaluate()`를 통해 탭 전환·카메라 종료 시 상태를 재평가하지만, `HomeDashboardScreen`에는 대응하는 refresh 훅이 없다.
- `HomeDashboardScreen`은 `initState`에서 사용자 정보·위치 인증·진행중 필름롤·근처 장소를 **1회만** 로드한다. 이후 route push(코스 선택, 필름롤 상세, 카메라 등)에서 복귀하거나 다른 탭에서 홈 탭으로 돌아와도 재조회하지 않는다.

🔄 재현 방법
---

1. 홈 진입 후 코스 선택 화면으로 이동해 코스를 선택한다.
2. 필름롤 상세에서 뒤로가기로 홈으로 복귀한다.
3. 홈의 "진행중 필름롤" 영역 / 진행률이 코스 선택 전 상태 그대로 표시되는 것을 확인한다.
4. (또는) 홈 → 채록길 탭으로 이동해 필름롤 상태를 바꾼 뒤 홈 탭으로 복귀한다 → 홈이 갱신되지 않는다.

📸 참고 자료
---

- `lib/features/home/presentation/main_tab_screen.dart` — `_onTabSelected()`는 `_exploreTabIndex`일 때만 `_exploreKey.currentState?.reevaluate()`를 호출, 홈 탭 복귀 시 갱신 로직 없음. `IndexedStack`으로 `HomeDashboardScreen` 상시 유지.
- `lib/features/home/presentation/home_dashboard_screen.dart` — `initState`에서만 `_fetchUserInfo` / `_ensureLocationVerified` / `_loadRecoveredFilmRoll` 실행. 외부에서 호출 가능한 refresh 진입점 없음.
- `lib/features/explore/presentation/explore_screen.dart` — `reevaluate()` 참고 패턴(홈에도 동일한 대칭 훅 필요).

✅ 예상 동작
---

- route에서 홈으로 복귀할 때(코스 선택 / 필름롤 상세 / 카메라 등) 홈 대시보드가 진행중 필름롤·진행률·가까운 채록 장소·사용자 정보를 재조회해 최신 상태를 반영한다.
- 다른 탭에서 홈 탭으로 재진입할 때도 동일하게 갱신한다(`ExploreScreen.reevaluate()`와 대칭되는 홈 refresh 훅 제공).
