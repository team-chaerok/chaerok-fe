# ⚙️[기능추가][필름롤] 현상결과 페이지 및 릴스 생성 API 연동

라벨: 작업전
담당자: @SeoHyun1024

---

## 📝 현재 문제점

- 필름롤이 현상 완료(`FilmRollStatus.completed`) 상태가 되어도, 그 결과를 보여주는 화면이 없다.
- 현상 대기 화면(`FilmRollDevelopingView`)에는 "현상이 완료되면 필름 컬렉션에서 확인할 수 있어요"라는 안내 문구만 있을 뿐, 실제 완료 결과 조회는 이번 범위 밖(후속 이슈)으로 명시되어 있다.
- 촬영한 사진을 릴스(짧은 영상)로 만들어주는 기능도 아직 백엔드 API 연동이 되어 있지 않다.
- 사용자가 현상이 끝난 뒤 결과(방문 장소, 사진, 릴스)를 앱 안에서 확인할 방법이 없다.

## 🛠️ 해결 방안 / 제안 기능

- 현상이 완료된 필름롤의 결과(방문 장소, 촬영 사진, 생성된 릴스)를 보여주는 "현상 결과" 페이지를 새로 만든다.
- 촬영한 사진을 기반으로 릴스를 생성하는 백엔드 API를 연동하고, 생성이 끝나면 현상 결과 페이지에서 재생/확인할 수 있게 한다.
- 현상 완료 상태를 감지해 현상 결과 페이지로 자연스럽게 연결되는 진입 동선을 정리한다.

## ⚙️ 작업 내용

- 현상 결과 페이지 UI 구성 (방문 장소 / 촬영 사진 / 릴스 확인)
- 릴스 생성 API 연동 (생성 요청, 진행 상태 확인, 결과 조회)
- 현상 완료 감지 → 현상 결과 페이지 진입 동선 연결
