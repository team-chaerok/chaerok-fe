# 🚀[기능개선][카메라] 카메라 상단 필름 타입 라벨 지역별 표시

라벨: 작업전
담당자: @SeoHyun1024

---

## 📝 현재 문제점

- 카메라(촬영) 화면 왼쪽 상단의 필름 타입 라벨이 필름 롤의 지역과 상관없이 항상 "공주:공주의 잔(殘)"으로 고정되어 있다.
- 부여·서산·예산 필름 롤로 촬영해도 공주 라벨이 표시되어 지역 정체성이 맞지 않는다.
- 관련 파일: `visit_capture_screen.dart`, `camera_top_bar.dart`, `region_code.dart`

## 🛠️ 해결 방안 / 제안 기능

- 촬영 중인 필름 롤의 지역에 맞춰 라벨을 표시한다.

| 지역 | 라벨 |
|------|------|
| 공주 | 공주:공주의 잔(殘) |
| 부여 | 부여:백제의 연(戀) |
| 서산 | 서산:서산의 낙(落) |
| 예산 | 예산:윤(潤) |

## ⚙️ 작업 내용

- 지역별 필름 이름 정의 (지역 코드 기준)
- 촬영 화면에서 필름 롤의 지역을 확인해 라벨에 반영
- 지역 정보를 불러오지 못한 경우에도 촬영이 중단되지 않도록 처리
- 지역별 라벨 테스트 추가
