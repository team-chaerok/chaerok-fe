# 채록 테스트 모드 가이드 (테스터용)

실제로 공주에 가지 않아도 채록의 전체 흐름
(**코스 선택 → 사진 촬영 → 방문 인증 → 현상**)을 끝까지 체험할 수 있는 모드입니다.
위치만 공주로 맞춰줄 뿐, 사진 업로드·기록·현상은 모두 실제로 동작합니다.

---

## 1. 테스트 모드 켜기

1. 나눠드린 **테스트용 앱**을 설치합니다.
2. 앱을 실행하고 평소처럼 **로그인**합니다.
3. 홈 화면 상단 **마이 페이지** 버튼을 누릅니다.
4. **`Test Mode (QA)`** 항목을 누릅니다.

> **`Test Mode (QA)` 항목이 안 보이나요?**
> 계정이 아직 테스터로 등록되지 않은 경우입니다. 담당자에게 로그인한 계정
> (카카오/구글/애플 중 무엇인지)을 알려주세요. 등록 후 앱을 껐다 켜면 나타납니다.

---

## 2. 순서대로 진행하기

패널의 버튼을 **위에서 아래로 하나씩** 누르면 됩니다.

| 순서 | 버튼 | 하는 일 |
| --- | --- | --- |
| 1 | **공주 진입** | 위치를 공주로 맞춥니다. 누른 뒤 **채록길 탭**에서 코스를 하나 선택하세요. |
| 2 | **관광지 인증 (TOURISM)** | 코스의 관광지에서 카메라가 열립니다. 사진을 찍어 인증합니다. |
| 3 | **음식점 인증 (FOOD)** | 같은 방식으로 음식점 사진을 찍어 인증합니다. |
| 4 | **카페 인증 (CAFE_DESSERT)** | 카페·디저트 장소 사진을 찍어 인증합니다. |
| 5 | **공주 이탈** | 공주를 벗어난 것으로 처리합니다. **채록길 탭**에 현상 시작 안내가 뜹니다. |

- 화면 위쪽 **진행 상태** 카드에서 각 단계가 체크(✓)되는지 확인할 수 있습니다.
- 2~4번 버튼은 **공주 진입 + 코스 선택**을 먼저 해야 활성화됩니다.
- 순서가 꼬였거나 처음부터 다시 하고 싶으면 **`테스트 상태 초기화`** 를 누르세요.

---

## 3. 참고 사항

- **앱을 완전히 종료하면** 테스트 진행 상태(공주 진입/이탈 등)는 초기화됩니다.
  이때는 **공주 진입**부터 다시 눌러 주세요.
- 촬영한 사진과 방문 기록, 현상 결과는 **실제 서버에 저장**됩니다. (테스트용 데이터로 취급됩니다.)
- 패널 아래 **QA 도구**(`충남 외 지역 홈 강제`, `로컬 DB 확인하기`)는 개발 확인용이므로
  테스트 시나리오에서는 사용하지 않아도 됩니다.

---

## 4. 문제가 생기면

- 특정 단계에서 "실패: ..." 안내가 뜨면 화면을 캡처해 담당자에게 전달해 주세요.
- 어떤 코스를 선택했는지, 몇 번 버튼에서 멈췄는지 함께 알려주시면 확인이 빠릅니다.
